    1. 已有课程加一讲：在 content/<课程ID>.json 的 lectures 数组末尾追加一个对象，必须含 8 个 section：overview / detail / keywords / examples / practice / exam / checklist / mapping，并写 part 指定所属章节（同名 part 会自动归入同一章）。
    2. 新增一门课：新建 content/<新ID>.json，写 id / order / name_zh / name_en / source_dir / summary / lectures。
    3. 在 study-site 目录运行 python build.py；再用 python build.py --check 确认 8 个板块齐全。
    4. 新讲会自动出现在总览、课程页、章节页、期末考点清单与合订本里，不必手改任何 HTML；页面仍是单文件、可离线打开。
