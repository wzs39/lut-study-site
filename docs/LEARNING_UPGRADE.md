# 学习功能升级约定

用户已确认需要全文搜索、继续学习、来源信息、自动检查、阅读工具、错题回顾、性能优化和多人资料共享八项改进。

## 能力与构建顺序

| 模块 | 责任 | 依赖 |
|---|---|---|
| search | 正文索引、课程/板块筛选、摘要高亮与深链接 | 现有章节/讲义标识 |
| learning-state | 四种学习状态、阅读位置、复习勾选兼容 | 讲义目录数据 |
| reading-practice | 字号/行距/专注、代码复制、大图、逐题自评与错题回看 | learning-state |
| provenance | 文件是否附上、页码、资料版本与核对日期 | 原始文件名与可选真实元数据 |
| media-readers | 图片预览优化、尺寸和每课合订本 | 原始图片和生成器 |
| sharing | 连接设置、只读连接测试、真实发布状态与同名历史 | 现有 Supabase / IndexedDB 接口 |
| verification | 单元/浏览器/链接与媒体检查、CI | 各模块验收条件 |

## 约束

- 保留静态、无框架、无 CDN 的站点架构及现有统一导航；保留全部课程正文、原图和答案。
- 全文索引可通过本地脚本加载，直接打开 HTML 也能搜索。查询结果应能定位到实际小节。
- 学习与练习记录仅在浏览器本地保存，兼容 `lut-review-v1`；保存失败应明确提示。允许导出备份与经验证的导入。
- 资料版本、核对日期及原始页码不以构建日期代替。未提供的字段显示“未记录”；不存在的原文件不生成假链接。
- 练习只做用户自评和收藏，不宣称自动判分。原文内容不因控件插入丢失。
- 图片预览保留原图入口；生成优化版本不覆盖原图。
- 云端设置只接受项目 URL 和公开客户端密钥，拒绝服务端密钥。连接检查只读，不自动上传测试数据。
- 缺少实际 Supabase 项目配置时，完成并验证接入功能，明确标注尚未启用真实共享；不伪造远端成功。
- 不推送或部署远端，不创建收费资源；本轮先完成可审阅的本地实现。

## 状态契约

- 讲义标识：`<course-id>/<lecture-slug>`；小节标识沿用现有 `sec-*` / `sN`。
- 学习状态：`new / learning / review / mastered`。
- 练习状态：`todo / done / wrong / retry`，收藏为独立布尔值；题目标识在讲义内按原顺序生成。
- 学习进度、错题与阅读偏好均使用带版本号的 JSON；读取时验证字段、长度和范围。
- 已有复习勾选迁移到同一讲义状态，已掌握与复习勾选保持一致；不清空旧存储。

## 验收

1. 用仅存在于正文的词语搜索，得到实际小节结果；筛选、摘要和跳转高亮可用，查询不被当作 HTML 执行。
2. 状态、阅读小节、阅读设置和错题刷新后保留；课程/首页/复习页的状态一致。
3. 元数据未知时不出现虚构日期、版本或附件；有效 PDF 页码链接、坏路径和不允许的 URL 均有测试。
4. 键盘可操作所有新控件；大图可关闭并返回焦点；手机下不出现整页溢出。
5. 新增每课合订本，保留全站合订本；优化图片可追溯到原图，且布局预留尺寸。
6. 共享接入支持配置校验、连接检查和准确状态；本地发布与模拟服务合同通过，真实服务是否启用单独报告。
7. 发布流程运行现有与新增单元测试、构建、链接/媒体检查和浏览器回归。
