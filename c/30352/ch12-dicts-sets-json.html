本节定位

这是全课程最后一讲新内容，也是把前面所有容器收口的一讲：字典用来「按键查找」，集合用来「去重与比较」，JSON 把嵌套数据存成文本。项目作业里的车辆、客户、交易记录，形状就是这一讲的「列表套字典」。

它同时回收了三条旧线：第 8 讲的列表与元组（字典的值常常是列表，items() 返回元组）、第 9 讲的文件读写（JSON 就是文件里的文本）、第 10 讲的模块（这一讲把你自己的文件变成模块）。

学完本讲你应当能够：

  • 创建字典、按键取值与赋值，并解释 KeyError 从哪来
  • 用字典统计频次，处理「新键先建初值」的问题
  • 把多条记录写成「列表套字典」，并遍历筛选
  • 说清浅拷贝与深拷贝的区别，知道什么时候必须 deepcopy
  • 用集合去重并做并、交、差、对称差运算
  • 用 DictReader 读 CSV、用 json 模块存取嵌套数据
  • 把自己的函数写成模块，并用 __main__ 判断隔离测试代码

一、先看数据处理的全貌

课件在第 10 章开头先讲了「数据」这件事本身（Chapter 10 Part 1 p3）：数据分析（data analytics）是把原始数据变成可用于决策的信息，分四层——数据层（数据库、API、CSV）、分析层（Python、R、Excel）、可视化层（图表、网页）、AI 层（机器学习）。这门课只做分析层里最基础的一段：用 Python 处理原始数据。

课件给的四个阶段（Part 1 p5）值得记住，因为每一阶段都对应一种数据结构：

阶段做什么本讲对应的结构
1. 数据收集 collection从公开数据、日志、CSV 里拿到原始数据文件读取（第 9 讲）
2. 数据处理 processing整理成表格、列表、对象等好处理的形状列表套字典（记录）
3. 数据清洗 cleanup去掉坏数据、补缺失、检查合理性字典遍历 + 条件判断
4. 探索性分析 EDA算统计量、找趋势字典计数、集合去重

二、字典：用键找值

2.1 创建与访问

字典（dictionary）是键值对（key-value pair）的集合（Part 2 p2）：每个值配一个键，用键就能直接取到值，不必知道它在第几个。

person = {
    "name": "John",
    "age": 30,
    "city": "New York"
}
print(person)
print(person["name"])
print(person["age"])
{'name': 'John', 'age': 30, 'city': 'New York'}
John
30

键必须是不可变类型：字符串、数字、元组可以，列表不行（TypeError: unhashable type）。值可以是任何东西，包括列表与另一个字典。

取值用方括号加键：person["name"]。键不存在时抛 KeyError——这是字典最典型的错误：

person = {"name": "John"}
print(person["age"])
KeyError: 'age'

2.2 修改与添加

字典是可变的（Part 2 p2）：赋值语句既能改已有的键，也能新建键——语法完全一样，区别只在键是否存在。

phone_numbers = {"Elon Musk": "555-3928372"}
phone_numbers["Elon Musk"] = "555-0000000"
phone_numbers["Bill Gates"] = "555-39482949"
print(phone_numbers)
{'Elon Musk': '555-0000000', 'Bill Gates': '555-39482949'}

正因为「赋值即新增」，拼错键名不会报错，只会多出一条没人用的数据。这类错误只能靠「打印出来看看」发现。

2.3 遍历

for 直接遍历字典时，拿到的是键（Part 2 p4）；要取值再用 d[key]：

my_dict = {"a": 1, "b": 2, "c": 3}
for key in my_dict:
    print(key, my_dict[key])
a 1
b 2
c 3

顺序按插入顺序（Python 3.7 起保证），但不要把它当排序结果——要排序请用 sorted()。

2.4 字典 vs 列表

课件用「按名字查电话」把两者对比得很清楚（Part 2 p5）：

维度列表字典
存法按顺序堆进去按键值对存
查找方式下标 L[2]，或循环比对值键 d["Sarah"]
查找代价与元素个数成正比（线性）基本恒定（哈希）
适合有顺序、要遍历、要排序按名字/编号快速查找
# 用列表：要循环找
names = ["Janne", "Elon"]
phones = ["555-492843", "555-2943483"]
for i in range(len(names)):
    if names[i] == "Elon":
        print(phones[i])

# 用字典：直接取
phone_numbers = {"Janne": "555-492843", "Elon": "555-2943483"}
print(phone_numbers["Elon"])
555-2943483
555-2943483

两个列表「平行存放」是常见但脆弱的写法：插入一个元素要同时改两个列表，一旦顺序错位，数据就全乱了。字典把键和值绑在一起，从结构上避免这种错位。

统计类程序的标准套路是「键存在就加一，不存在就建 1」，可以写成 d[k] = d.get(k, 0) + 1（get 属拓展），也可以先判断 if k in d。两种写法都不报错，直接写 d[k] += 1 在第一次遇到新键时会抛 KeyError。

四、列表 + 字典：一条记录

真实数据通常是一堆「结构相同的记录」，每条记录用字典，整体用列表装（Part 2 p9）。这是本课处理 CSV、JSON 的通用形状。

cars = [
    {"brand": "Ford", "year": 2015, "price": 15000},
    {"brand": "Skoda", "year": 2012, "price": 5000}
]

for car in cars:
    if car["brand"] == "Ford":
        print("Year of the Ford is:", car["year"])
Year of the Ford is: 2015

读法：car 是一条记录（字典），car["year"] 取这一条的年份。要统计「每个品牌几辆车」，就用「品牌做键、数量做值」的字典累加。

五、浅拷贝与深拷贝

课件专门讲了这一对概念（Part 2 p10–p11），因为它在「复制一份再改」时是隐形杀手。

person = {"name": "John", "city": ["Helsinki", "Tallinn"]}
shallow = person.copy()
shallow["city"][0] = "Stockholm"

print(person)
print(shallow)
{'name': 'John', 'city': ['Stockholm', 'Tallinn']}
{'name': 'John', 'city': ['Stockholm', 'Tallinn']}

copy() 只复制了最外层：新字典的 city 仍指向同一个列表，所以改浅拷贝里的列表，原字典也变。

import copy

person = {"name": "John", "city": ["Helsinki", "Tallinn"]}
deep = copy.deepcopy(person)
deep["city"][0] = "Oslo"

print(person)
print(deep)
{'name': 'John', 'city': ['Helsinki', 'Tallinn']}
{'name': 'John', 'city': ['Oslo', 'Tallinn']}

copy.deepcopy() 递归复制所有层，两个对象彻底独立。判断标准很简单：值里有列表/字典等可变对象，就要深拷贝。

六、集合：只关心「有没有」

集合（set）像数学里的集合（sets p2）：元素不重复、没有顺序、用花括号写。它最适合两件事——去重与 membership 判断。

numbers = [1, 2, 2, 3, 3, 3]
unique = set(numbers)
print(len(numbers), len(unique))
print(sorted(unique))

empty = {}      # 这是空字典，不是空集合！
empty_set = set()
print(type(empty), type(empty_set))
6 3
[1, 2, 3]
<class 'dict'> <class 'set'>

元素必须可哈希（hashable），也就是不可变：整数、字符串、元组可以，列表与字典不行（sets p3）。原因是集合用哈希表实现，靠哈希值快速定位。

6.2 集合运算

这是集合最有价值的部分，方法与运算符一一对应（sets p6–p7）：

运算方法运算符含义
并集a.union(b)a | b两边的全部元素
交集a.intersection(b)a & b两边都有的
差集a.difference(b)a - b在 a 不在 b
对称差a.symmetric_difference(b)a ^ b只在一边出现的
子集a.issubset(b)a <= ba 全在 b 里
超集a.issuperset(b)a >= ba 包含 b
IEEE = {"Python", "Java", "JavaScript", "C++", "TypeScript"}
TIOBE = {"Python", "C++", "Java", "C", "C#"}

print(sorted(IEEE | TIOBE))
print(sorted(IEEE & TIOBE))
print(sorted(IEEE - TIOBE))
print(sorted(IEEE ^ TIOBE))
['C', 'C#', 'C++', 'Java', 'JavaScript', 'Python', 'TypeScript']
['C++', 'Java', 'Python']
['JavaScript', 'TypeScript']
['C', 'C#', 'JavaScript', 'TypeScript']

课件留了四个问题（sets p9）：两个榜单里出现过的语言（并集）、同时上榜的（交集）、只在 IEEE 的（差集）、只在一个榜单的（对称差）。上面四行输出就是四个答案，注意结果都先 sorted() 再打印——集合无序，直接打印每次顺序可能不同。

七、CSV 的 DictReader

第 9 讲用 split(",") 手工切 CSV。字段里若含逗号或引号，手工切就会错位；标准库的 csv 模块能正确处理，DictReader 还会把每行变成字典（Part 3 p4–p5）：

import csv

csvfile = open("csv_e04.csv")
reader = csv.DictReader(csvfile)
for row in reader:
    print(row["name"], row["age"], row["gender"])
csvfile.close()
Alice 25 Female
Bob 30 Male
Charlie 28 Male

csv_e04.csv 的第一行是表头 name,age,gender；DictReader 用它当键，于是可以按列名取值 row["age"]，不必记「年龄是第 1 列」。值仍是字符串，算术前要 int()。

八、JSON：能装嵌套结构的数据格式

CSV 只能表示「二维表」，装不了嵌套。JSON（JavaScript Object Notation）用花括号表示对象、方括号表示数组，能表达任意层嵌套（Part 4 p2）。它起源于 2000 年代初，现在是配置文件与网络接口的事实标准。

JSON 与 Python 字典长得很像，但有两条硬差别（Part 4 p3）：

维度Python 字典JSON
键的类型任何不可变类型只能是字符串
字符串引号单双引号都行必须双引号
额外值True / False / Nonetrue / false / null
注释可以有 #不允许
import json

person = {"name": "Alice", "age": 25, "hobbies": ["reading", "coding"]}
text = json.dumps(person)
print(text)

back = json.loads(text)
print(back)
print(type(back))
{"name": "Alice", "age": 25, "hobbies": ["reading", "coding"]}
{'name': 'Alice', 'age': 25, 'hobbies': ['reading', 'coding']}
<class 'dict'>

json.dumps() 把对象变成字符串（dump string），json.loads() 把字符串变回对象；读写文件用 json.dump() / json.load()（没有 s）。四个名字只差一个字母，方向记法：s = string。

import json

books = [
    {"title": "Python Basics", "year": 2020},
    {"title": "Data Handling", "year": 2023}
]

file = open("books.json", "w")
json.dump(books, file)
file.close()

file = open("books.json", "r")
loaded = json.load(file)
file.close()
print(len(loaded), loaded[0]["title"])
2 Python Basics

多个对象存成 JSON 的标准形状是「对象数组」：外层方括号，里面每个元素是一个花括号对象。读回来就是一个「列表套字典」，与第四节的结构完全一致。

九、把自己的函数变成模块

第 10 讲用的是别人的模块；这一节把自己的代码变成模块（Part 5 p2–p3）。做法只有四步：

  1. 新建一个 .py 文件，名字是合法的 Python 标识符（如 calculator.py）
  2. 在里面写函数、类、常量
  3. 把文件放在与调用者相同的目录（最简单）
  4. 在另一个文件里 import calculator，然后 calculator.add(2, 3)
# calculator.py
PI = 3.14159

def add(x, y):
    return x + y

def divide(x, y):
    if y == 0:
        return "Cannot divide by zero"
    return x / y
# main.py
import calculator

print(calculator.PI)
print(calculator.add(2, 3))
print(calculator.divide(10, 0))
3.14159
5
Cannot divide by zero

导入时 Python 会生成一个 __pycache__ 目录，里面是编译后的字节码，用来加速下次导入（Part 5 p5）。它不是给人读的，可以删掉，删了也不影响运行；打包给别人时最好删掉。

9.1 if __name__ == "__main__"

一个文件既可能被「直接运行」，也可能被「导入」。导入时我们不希望它的测试代码自动执行，于是用这个判断把「只有直接运行时才做的事」包起来（Part 5 p6）：

# greet_module.py
def greet(name):
    return "Hello, " + name

if __name__ == "__main__":
    print(greet("world"))
    print("This runs only when the file is executed directly.")
# other.py
import greet_module
print(greet_module.greet("Alice"))

直接运行 greet_module.py 会打印那两行；被 other.py 导入时只输出 Hello, Alice，因为此时 __name__ 是 "greet_module" 而不是 "__main__"。项目作业里把测试代码放进去，评分脚本导入你的模块时才不会被打扰。

十、常见错误与调试

KeyError：键不存在或拼错d["nmae"] 一定报错。print(d) 看真实键名；不确定时用 if key in d 先判断，或 d.get(key, default) 取默认值。
{} 是空字典不是空集合空集合只能写 set()。type({}) 是 dict，很多「去重没生效」的 bug 就出在这里。
对集合下标 / 排序集合无序，s[0] 直接抛 TypeError。要顺序就先 sorted(s) 变成列表。
copy 之后改嵌套仍影响原数据d.copy() 是浅拷贝。含列表/字典的值要 copy.deepcopy()。
JSON 报错先看引号json.loads("{'a': 1}") 抛 JSONDecodeError，因为 JSON 只认双引号。把单引号换成双引号，或干脆用 json.dumps 生成字符串。
前后衔接

这一讲回收三条旧线：字典的值是列表、items() 返回元组（容器讲），JSON 是文件里的文本（文件讲），函数写进 .py 就是模块。数据四阶段——收集、处理、清洗、探索分析——对应“文件读取 → 列表套字典 → 字典遍历加判断 → 字典计数与集合去重”。真实记录就是列表套字典：一条记录一个 dict，car["year"] 取字段。

常见误解

字典赋值即新增，拼错键名不报错，只会多出无用数据——只能靠打印发现；直接 d[k] += 1 第一次遇新键抛 KeyError，要先判断或用 d.get(k, 0) + 1。copy() 是浅拷贝，值里有可变对象时改浅拷贝会动到原对象，要 copy.deepcopy。空集合写 set()，{} 是空字典；集合无序，打印前先 sorted()。

例 1　用字典做一个电话簿：加入三条记录，按名字查询，删除一条后打印全部。

「键是姓名、值是号码」是最小可用的字典；遍历时同时打印键与值。

phone_book = {}
phone_book["Alice"] = "555-0101"
phone_book["Bob"] = "555-0202"
phone_book["Charlie"] = "555-0303"

print(phone_book["Bob"])
print("Bob" in phone_book)

del_number = phone_book.pop("Charlie")
print("removed:", del_number)

for name in phone_book:
    print(name, phone_book[name])

输出：

555-0202
True
removed: 555-0303
Alice 555-0101
Bob 555-0202

解释：空字典写 {}；赋值即新增；in 只查键；pop 删除并返回值。若查一个不存在的名字，例如 phone_book["Dan"]，会抛 KeyError——所以查之前通常先 in 一下。

例 2　统计一段文字里每个单词出现的次数，并按次数从高到低输出前三名。

「单词做键、次数做值」是字典最经典的用法；排序时用 sorted 的 key 参数按值排（拓展用法，理解即可）。

text = "the quick brown fox jumps over the lazy dog the fox"
words = text.split()

counts = {}
for w in words:
    if w in counts:
        counts[w] = counts[w] + 1
    else:
        counts[w] = 1

pairs = sorted(counts.items(), key=lambda kv: kv[1], reverse=True)
for word, n in pairs[:3]:
    print(word, n)

输出：

the 3
fox 2
quick 1

解释：if w in counts 分支保证第一次遇到新词时先建 1，否则 counts[w] += 1 会 KeyError；counts.items() 把键值对变成 (key, value) 元组列表（第 8 讲解包）；key=lambda ... 指定按值排序。若不想用 lambda，可以先按次数把字典反转再排序，思路相同。

例 3　给定两个集合，输出并集、交集、只在第一个集合里的元素，以及「恰好在一个集合里」的元素。

四个问题正好对应四种集合运算，结果都先 sorted() 再打印，避免顺序随机。

A = {"Python", "Java", "C++", "Go"}
B = {"Python", "C#", "Java", "Rust"}

print("union:", sorted(A | B))
print("intersection:", sorted(A & B))
print("only A:", sorted(A - B))
print("exactly one:", sorted(A ^ B))

输出：

union: ['C#', 'C++', 'Go', 'Java', 'Python', 'Rust']
intersection: ['Java', 'Python']
only A: ['C++', 'Go']
exactly one: ['C#', 'C++', 'Go', 'Rust']

解释：^ 是「并集减去交集」，等价于 (A | B) - (A & B)。若把集合换成列表做同样的事，就得写四层循环加 in 判断——这就是集合的价值。

例 4　把字典写成 JSON 文件，再读回来修改一个字段并写回。

写用 json.dump，读用 json.load，两侧都要 open / close（第 9 讲）。

import json

config = {"user": "alice", "theme": "dark", "font_size": 14}

file = open("config.json", "w")
json.dump(config, file)
file.close()

file = open("config.json", "r")
loaded = json.load(file)
file.close()

loaded["font_size"] = 16
print(loaded)
print(json.dumps(loaded))

输出：

{'user': 'alice', 'theme': 'dark', 'font_size': 16}
{"user": "alice", "theme": "dark", "font_size": 16}

解释：json.dump 直接写进文件对象；读回来是普通字典，可以照常改；json.dumps 把结果变回字符串看格式。注意 JSON 输出里全是双引号——这正是它与 Python 字典打印结果的区别。

操作清单

选数据结构

  1. 数据是「一串有序的值」→ 列表
  2. 数据是「按名字/编号查的值」→ 字典
  3. 数据要「去重」或「判断有没有」→ 集合
  4. 数据是「一条记录多个字段」→ 字典；多条记录 → 列表套字典
  5. 数据要跨程序保存、还要嵌套 → JSON 文件

写完后的检查

  • 访问字典前，键是否一定存在（必要时先 in）
  • 统计计数时，新键是否先建了初值
  • 复制含嵌套的字典用了 deepcopy
  • 打印集合前先 sorted()
  • JSON 的键都是字符串、引号都是双引号
  • 自己的模块被导入时，测试代码放在 __main__ 判断里
