11.1 元组：不可变的有序集合（tuples.pdf）

元组（tuple）把一组元素按固定顺序放在一起，用圆括号和逗号创建。与列表唯一的本质差别是不可变：创建后不能增删改元素。

point = (3, 5)
rgb = (255, 128, 0)
single = (42,)      # 一个元素也要留逗号
empty = ()
print(point[0], point[-1])   # 3 5
print(len(rgb))              # 3

正因为不可变，元组可以放进集合、可以当字典的键；列表不行。元组适合存「不该被改动」的数据：坐标、RGB 颜色、函数返回的多值。

对比项tuplelist
可变性不可变可变（append/remove/赋值）
括号()[]
能否作集合元素/字典键可以（可哈希）不可以
遍历与访问速度通常更快、更省内存因可变性略有开销
内置方法只有 count()、index()大量方法

元组只有两个方法：count(x) 数出现次数，index(x) 返回第一次出现的下标。

t = (1, 2, 2, 3)
print(t.count(2))   # 2
print(t.index(3))   # 3

返回多个值：Python 函数表面只能返回一个对象，用元组就能「打包」多个值，调用处再解包。

def min_max(nums):
    return min(nums), max(nums)

low, high = min_max([3, 1, 7])
print(low, high)   # 1 7

11.2 集合：无序、去重、可哈希（sets.pdf）

集合（set）对应数学集合：用花括号写元素，或用 set() 从列表/元组构造。三个特征：元素不重复、没有顺序与下标、本身可变但元素必须不可变。

a = {1, 2, 2, 3}
print(a)              # {1, 2, 3}
b = set([3, 3, 4])
print(b)              # {3, 4}
print(2 in a)         # True

集合用哈希表实现：加入元素时先算哈希值，因此元素必须可哈希（整数、字符串、元组可以；列表、字典不行）。这也是集合查找为 O(1) 的原因。

运算写法结果示例
并集a | b 或 a.union(b){1,2,3} | {3,4} = {1,2,3,4}
交集a & b 或 a.intersection(b){1,2,3} & {3,4} = {3}
差集a - b 或 a.difference(b){1,2,3} - {3,4} = {1,2}
对称差a ^ b{1,2,3} ^ {3,4} = {1,2,4}
易错{} 是空字典不是空集合；空集合必须写 set()。另外集合没有下标，s[0] 会报 TypeError。

11.3 三种容器互转（type_conversions.pdf）

目标函数顺序重复元素
listlist(t)保持原顺序（set 转 list 顺序不定）保留
tupletuple(l)保持原顺序保留
setset(l)无顺序自动去重
l = [3, 1, 3, 2]
print(list(set(l)))    # 顺序不定，长度 3
print(tuple(l))        # (3, 1, 3, 2)
print(set(tuple(l)))   # {1, 2, 3}

用集合去重的经典写法是 list(set(l))，但要注意结果顺序不可依赖；需要「去重且保序」时，用循环 + 已见集合自己实现。

11.5 安装 NumPy（installing_numpy.pdf）

  1. 打开终端（Terminal / PowerShell / cmd）
  2. 确认 pip：pip --version
  3. 升级 pip：pip install --upgrade pip
  4. 安装：pip install numpy
  5. 验证：python -c "import numpy; print(numpy.__version__)"
国内网络下载慢时可换镜像源：pip install numpy -i https://pypi.tuna.tsinghua.edu.cn/simple；装错版本用 pip install numpy==1.26.4 固定版本。

11.6 使用 NumPy（using_numpy.pdf）

NumPy 的核心是 ndarray：同类型元素、连续内存、固定形状。它支持逐元素运算、广播、矩阵乘法与统计函数，比嵌套列表快一个数量级。

import numpy as np

a = np.array([1, 2, 3, 4, 5])          # 一维
m = np.array([[1, 2, 3], [4, 5, 6]])   # 二维
print(m.shape)        # (2, 3)
print(m[1, 2])        # 6
print(a * 2)          # [2 4 6 8 10]
print(m.sum(axis=0))  # 每列之和 [5 7 9]
print(np.zeros((3, 3)))
print(np.ones((2, 4)))
操作写法说明
创建np.array(list)从列表/嵌套列表构造
全零/全一np.zeros(shape) / np.ones(shape)参数是元组
形状arr.shape返回 (行, 列)
变形arr.reshape(3, 2)元素总数必须一致
矩阵乘a @ b 或 np.dot(a, b)不是逐元素乘
统计arr.sum(axis=0/1)按列/按行求和
易错a * b 是逐元素乘，矩阵乘要用 a @ b；reshape 不改变原数组，返回新数组。

11.9 补全：元组与 NumPy 的原版课件知识点（Chapter 11 slides 落地）

元组（tuple）四要点（tuples.pdf）：① 不可变（immutable）——创建后不能增删改元素；② 有序——按下标访问；③ 可混装——整数、字符串、甚至其他元组/列表/字典都能放；④ 语法：point = (3, 5)、color = (255, 128, 0)，访问 point[0]。

English中文说明 / 例句
immutability不可变性不能 add/remove/modify；这是元组与列表的根本区别
return multiple values返回多个值函数默认只能返回一个值；用元组实现多返回值：def min_max(xs): return min(xs), max(xs)
packing / unpacking打包 / 解包a, b = 1, 2 与 x, y = point；星号解包 *rest 收集剩余元素
tuple vs list元组 vs 列表() vs []；元组更快更省内存（不可变开销小）；列表可变适合增删改
count() / index()仅有的两个方法t.count(x) 计出现次数；t.index(x) 求第一个下标
fixed collection固定集合场景坐标 (x, y)、RGB 颜色三元组、星期几等「不该被改」的数据

NumPy 三页课件的要点链（installing_numpy.pdf → using_numpy.pdf）：

  1. 安装：NumPy 不在标准库里，用 pip 安装（课程提供 installing_numpy.pdf 指引），导入约定为 import numpy as np
  2. 创建：np.array([1,2,3,4,5]) 一维；np.array([[1,2,3],[4,5,6]]) 二维；np.zeros((3,3)) / np.ones((2,4)) 按形状造
  3. 特性：连续内存块存储 → 元素访问与数学运算更快；尺寸创建时固定，形状可用 reshape 改
  4. 能力：线性代数、统计运算、傅里叶变换等科学计算函数库
  5. 对比：列表逐元素运算要写循环，NumPy 直接 a * 2、a + b 整组算（向量化）
易错① 元组只有一个元素时要写 (3,)（带逗号），(3) 只是整数 3；② np.array 里混入不同长度的嵌套列表不会得到二维数组，而是 dtype=object 的一维；③ 元组「不可变」指顶层元素不可重新赋值，嵌在里面的列表内容仍可改。

例题 1：去重并保序

把 [3, 1, 3, 2, 1] 去重且保持首次出现顺序。

直接用 list(set(l)) 会丢顺序。正确做法是用一个已见集合：

seen = set()
out = []
for x in l:
    if x not in seen:
        seen.add(x)
        out.append(x)

例题 2：元组做字典键

统计网格中每个坐标出现的次数，坐标用 (row, col) 表示。

元组可哈希，能直接做键：counts[(r, c)] = counts.get((r, c), 0) + 1。若用列表 [r, c] 会抛 TypeError: unhashable type。

例题 3：NumPy 求列平均

给定 3×2 矩阵，求每列平均值。

m.mean(axis=0) 返回长度 2 的数组；axis=0 表示沿行方向压缩，即按列统计。若写成 axis=1 得到每行平均。

练习

1. 写出把 [1, 2, 2, 3] 变成 (1, 2, 2, 3) 与 {1, 2, 3} 的代码。

答案与思路

tuple(l) 保序保重复；set(l) 去重且无序。

2. 为什么 {[1,2]} 会报错？怎么改？

答案与思路

列表不可哈希，不能放进集合；改成元组 {(1,2)}。

3. 解释 pip、PyPI、package 三者的关系。

答案与思路

PyPI 是索引站，pip 是从 PyPI 下载安装的工具，package 是被安装的包（如 numpy）。

4. 用 NumPy 创建 3×3 全零矩阵并把中心设为 1。

答案与思路

m = np.zeros((3,3)); m[1,1] = 1，下标从 0 开始。

练 1 · 元组判型

下面四行各自发生什么？t=(3)、t=(3,)、t=(3,5); t[0]=9、a,b=(1,2,3)（最后一行会不会报错？怎么改成合法？）

参考答案

① (3) 是整数 3（括号被当运算符）；② (3,) 才是单元素元组；③ TypeError——不可变，不能赋值；④ 报 ValueError，因为左边 2 个名字右边 3 个值；改成 a,b,_=(1,2,3) 或 a,*rest=(1,2,3)。

练 2 · 多返回值

写一个函数 stats(xs) 同时返回列表的最小值、最大值与平均值，并在调用处用解包接住。

参考答案

def stats(xs):
    return min(xs), max(xs), sum(xs)/len(xs)

lo, hi, avg = stats([2, 8, 3])
print(lo, hi, avg)  # 2 8 4.333...

原理：return 后面的逗号创建元组；左边三个名字做解包——课件 p7 的标准用法。

考点与难点

必考
  • 元组与列表的三点区别（可变性、括号、可否作键）
  • 元组解包返回多值
  • 集合去重与交并差运算
  • 三种容器互转后的顺序与去重行为
  • 模块/包/PyPI/pip 的概念区分
  • NumPy 数组创建、shape、axis 统计
易错
  • 空集合写成 {}（那是字典）
  • 用 list(set(l)) 后依赖顺序
  • 把元组当可变对象去赋值
  • 矩阵乘用 * 而不是 @
  • reshape 以为原地修改
进阶

能解释「集合查找为什么是 O(1)」「NumPy 为什么比嵌套列表快」，把哈希表与连续内存两件事讲清楚，是本章的加分点。

方法清单

  1. 先问数据会不会变：会变用 list，不会变用 tuple
  2. 需要去重或集合运算时再转 set，别过早转换
  3. 要保序去重就用「已见集合 + 输出列表」
  4. 用元组做复合键前确认元素都可哈希
  5. 第三方包先 pip install，再 import，最后验证版本
  6. NumPy 统计先确认 axis：0 按列，1 按行
