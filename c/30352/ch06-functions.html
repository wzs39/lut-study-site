本节定位

前五讲的代码都是「一条一条往下写」。程序一变长，重复的片段就会出现，改一处要改十处。这一讲把代码打包成函数：给名字、留入口（参数）、留出口（返回值），以后随时调用。

循环与函数是这门课的两根支柱：循环解决「重复」，函数解决「复用与结构」。后面第 7 讲的类、第 9 讲的文件处理、第 12 讲的项目作业，都是「若干函数 + 一个主流程」的形态。

学完本讲你应当能够：

  • 用 def 写出带参数、带返回值的函数，并解释五个组成部分
  • 说清 return 与 print 的区别，知道没有 return 时函数返回 None
  • 按位置正确传参，解释为什么参数个数与顺序都不能错
  • 用默认参数给可选参数设默认值，并避开「可变默认参数」陷阱
  • 解释局部变量的独立性，以及为什么列表传进函数会被改到
  • 按「定名称 → 定输入 → 定输出 → 定判定 → 定累加」五步设计一个函数

一、函数是什么，为什么要用

课件给的定义很短：函数是一个「小程序」，专门完成某一件事（What is a function p2）。它把一段代码打包、起名字、留出入口（参数）与出口（返回值），以后在程序任何地方都能再叫它一次。

用函数有三层收益：

  • 结构：把长程序切成若干块，每块只做一件事，读代码时不必一次装进脑子；
  • 复用：定义一次，调用无数次，改一处就全改；
  • 协作：把一组函数写成一个库（library），别人 import 就能用——这正是第 10 讲「模块」的由来。

课件还提到一个特殊情形：函数可以调用自己，叫递归（recursion）。这门课不深入递归，但要知道它是函数机制自然允许的。

1.1 内置函数与自定义函数

前几讲一直在用内置函数（built-in functions）：print()、input()、len()、int()、float()、str()、round()、range()。它们随 Python 一起装好，不用导入就能用。

这门课的重点是自定义函数（user-defined functions）：为了解决自己的问题而写的函数（What is a function p5）。两者用法完全一样——都是「给输入、拿输出」。

课件的 round() 例子值得细看（p4）：它接受两个输入，第一个是要处理的数，第二个是保留几位小数，顺序不能反。

print(round(3.14159, 2))
print(round(6.7, 0))
print(round(3.14159))
3.14
7.0
3

round(6.7, 0) 得 7.0 而不是 7：只要给了第二个参数，返回类型就是 float。这提醒我们：函数的返回值有类型，用之前要知道拿到的是什么。

二、用 def 定义函数

2.1 骨架的五个部分

定义函数的语法（Self-defined functions p2–p5）可以拆成五块：

def function_name(parameters):
    # function body
    return result
部分作用规则
def声明「这里开始定义一个函数」关键字，不能拼错
function_name函数的名字小写、用下划线分词，描述它做什么
(parameters)参数列表，函数的输入逗号分隔；没有参数也要写一对空括号
:函数头结束，函数体开始漏了就是 SyntaxError
缩进的函数体函数真正执行的代码整块必须比 def 多缩进
return result把结果交回调用者可以没有，也可以在中间提前返回

命名规范与变量一致：只能字母、数字、下划线，不能有空格，不能以数字开头；习惯全小写 + 下划线（count_vowels），而不是 CountVowels 或 cv。名字要让人只看名字就知道它做什么。

2.2 一个最小可运行函数

def greet(name):
    message = "Hello, " + name + "!"
    return message

result = greet("Alice")
print(result)
Hello, Alice!

三行代码里发生了三次「跨边界」：调用时 "Alice" 被复制给参数 name；函数体算出一个新字符串；return 把它交给调用处，赋给 result。函数内部的 message 在外面看不见（下一节讲作用域）。

三、return：函数唯一的出口

3.1 return 结束执行并交回一个值

return 做两件事：立刻结束函数的执行；把后面的表达式作为返回值交给调用者（p6）。return 之后的语句永远不会执行。

def check(n):
    if n < 0:
        return "negative"
    return "non-negative"

print(check(-5))
print(check(0))
negative
non-negative

一个函数里可以有多条 return，但每次调用只会执行其中一条——上面就是「负数提前返回」的写法，避免了层层嵌套的 if。这种提前返回叫守卫式写法（guard clause），第 4 讲已经用过同样的思路。

3.2 return 与 print 不是一回事

这是本章最容易混的一点（p6）：print() 只是把文字显示到屏幕上，不产生值；return 才把值交回给调用者。

def add_print(a, b):
    print(a + b)

def add_return(a, b):
    return a + b

x = add_print(2, 3)
y = add_return(2, 3)
print("x is", x)
print("y is", y)
5
x is None
y is 5

add_print 把 5 打在屏幕上，但它的返回值是 None，所以 x 拿到的是 None。CodeGrade 的反馈里那句 The function should return a value（CG Guide）对应的就是这个错误：该 return 的地方写了 print。

3.3 没有 return 的函数返回 None

如果函数体里根本没有 return，Python 会在函数结束时自动返回 None（none.py）。None 是第 1 讲介绍过的「空值」类型，表示「没有值」。

def show(word):
    print(word)

value = show("Cat")
print("value is", value)
Cat
value is None

反过来，return 不带表达式也返回 None，常用于「提前结束、不返回东西」的场景：

def divide(a, b):
    if b != 0:
        return a / b

result = divide(10, 0)
if result is None:
    print("Error: Division by zero!")
else:
    print(result)
Error: Division by zero!

注意判断用的是 is None 而不是 == None：None 是单例对象，is 比较的是「是不是同一个对象」，语义更准确。

忘写 return 是最常见的丢分点函数算出了结果却只用 print 显示，调用处拿到 None，后续计算全错。写完函数先问自己：调用者需要这个值吗？ 需要就 return。

四、调用函数：把值送进去

定义只是「写好一份说明书」，真正执行要调用（call）：写函数名加括号，括号里给实参（p7）。

def fun(p):
    return p * 2

x = 66
y = fun(x)
print(y)
132

调用时发生的事：实参 x 的值被复制给形参 p；函数体用 p 算出结果；return 把结果交回；赋值语句把它存进 y。整条链上 x 本身没有被改动。

函数必须先定义、后调用。把调用写在 def 之前会抛 NameError: name 'fun' is not defined——Python 从上往下执行，定义也是一个「执行动作」。

五、参数：位置、数量、顺序

5.1 按位置对应

参数按位置一一对应（Parameters p2）：第一个实参给第一个形参，第二个给第二个。数量和顺序都不能错。

def describe(name, age):
    return name + " is " + str(age) + " years old"

print(describe("Alice", 30))
print(describe(30, "Alice"))
Alice is 30 years old
30 is Alice years old

第二个调用不报错，但语义完全错了——这正是「顺序有意义」的意思。参数个数不对则会直接抛 TypeError：

def describe(name, age):
    return name + " is " + str(age) + " years old"

print(describe("Alice"))
TypeError: describe() missing 1 required positional argument: 'age'

5.2 为什么必须用参数，而不是靠外面的变量

课件强调：函数需要的所有「外部信息」都必须通过参数传进来（Parameters p4）。这样做换来三件事——函数独立（不偷偷依赖全局状态）、可复用（换个输入就能用）、可测试（给定输入就能验证输出）。

反面例子：函数直接读一个全局变量 PI 或 tax_rate，换一个场景就得改函数体。写成 def total(price, tax_rate)，函数就能在任何地方用。

5.3 默认参数

默认参数（default parameter）让某个参数「可以不传」，不传时用预先写好的值（Parameters p5）：

def greet(name, greeting="Hello"):
    return greeting + ", " + name + "!"

print(greet("Alice", "Hi"))
print(greet("Bob"))
Hi, Alice!
Hello, Bob!

两条规则：第一，有默认值的参数必须放在没有默认值的参数后面，写成 def f(a=1, b) 是语法错误；第二，默认值只在定义时求值一次，之后每次调用共用同一个对象。

可变默认参数是经典陷阱def add_item(x, box=[]) 里的 [] 只创建一次，所有调用共用同一个列表：add_item(1) 得 [1]，再调 add_item(2) 得 [1, 2]。正确写法是把默认值设为 None，进了函数再判断：if box is None: box = []。
def add_item(x, box=[]):
    box.append(x)
    return box

print(add_item(1))
print(add_item(2))
[1]
[1, 2]

六、作用域：函数里的名字是独立的

6.1 局部变量

函数体内定义的变量与参数都是局部的（local）：只在这个函数里存在，函数返回就消失，别的函数看不到（Parameters p3）。所以两个函数各有一个 n 互不干扰。

def f1():
    n = 1
    return n

def f2():
    n = 2
    return n

print(f1(), f2())
1 2

如果函数里给一个「外面已有」的变量赋值，Python 会把它当成新的局部变量，外面的同名变量不变。想改外面的变量得用 global，但这门课不建议这么做——用参数传入、用 return 传出，才是可维护的写法。

6.2 值传递：改参数不影响外面的不可变对象

add_one.py 是课件给出的追踪练习：

def add_one(nr):
    nr = nr + 1
    x = 2 * nr
    return x

x = 10
y = 7
print("returned:", add_one(y))
print("x and y now:", x, y)
returned: 16
x and y now: 10 7

为什么 y 仍是 7？因为 y 的值被复制给 nr，函数里改的是副本。同理函数里的局部变量 x 与外面的 x 是两个不同的名字，互不影响。

6.3 例外：传入可变对象时会被改到

列表、字典是可变对象（mutable），传参时复制的是「指向同一个对象的引用」而不是内容。函数里改元素，外面的列表跟着变（list_parameter.py）：

def modify_parameter(my_list):
    my_list[2] = 33
    A = my_list
    A[0] = 1000

original_list = [1, 2, 3]
print("Before:", original_list)
modify_parameter(original_list)
print("After:", original_list)
Before: [1, 2, 3]
After: [1000, 2, 33]

第 8 讲会系统讲列表，这里先记住结论：不可变对象（数字、字符串、元组）传进函数，外面不变；可变对象（列表、字典、集合）传进去，函数里的修改会反映到外面。

七、从需求到函数：设计五问

课件用一个具体的题示范设计流程（Example: writing a function p2）：写一个函数，返回字符串里元音字母的个数。动笔之前先回答五个问题：

  1. 函数叫什么名字？→ count_vowels（动词 + 名词，说明它做什么）
  2. 参数是什么？→ 一个字符串 s
  3. 返回什么？→ 一个整数（个数），不是打印
  4. 怎么判断一个字符是不是元音？→ ch.lower() in "aeiou"
  5. 怎么数？→ 计数器初值 0，命中就 +1；用不用循环？→ 要遍历每个字符，用 for
def count_vowels(s):
    count = 0
    for ch in s.lower():
        if ch in "aeiou":
            count = count + 1
    return count

print(count_vowels("Programming is fun"))
5

这五个问题就是「通用解题思路」：定名称 → 定输入 → 定输出 → 定判定条件 → 定累加方式。换成「统计及格人数」「数出单词个数」都是同一套问法。

八、用函数组织一个完整程序

课件的 example_with_menu.py 把「面积计算器」拆成五个函数：一个打印菜单并读选择，三个算面积，一个算平方根；主程序是一个 while 循环，按选择调用对应函数。

def print_menu():
    """Print the menu and return the user's choice."""
    print("\nCompute the area of:")
    print("1) a circle")
    print("2) a rectangle")
    print("3) a triangle")
    print("4) quit")
    return int(input("Enter your choice: "))

def circle_area(r):
    return 3.14159 * r ** 2

def rectangle_area(w, h):
    return w * h

def triangle_area(a, b, c):
    s = (a + b + c) / 2
    return (s * (s - a) * (s - b) * (s - c)) ** 0.5

choice = print_menu()
if choice == 1:
    r = float(input("Radius: "))
    print("Area:", round(circle_area(r), 2))
elif choice == 2:
    w = float(input("Width: "))
    h = float(input("Height: "))
    print("Area:", round(rectangle_area(w, h), 2))
elif choice == 3:
    a = float(input("Side 1: "))
    b = float(input("Side 2: "))
    c = float(input("Side 3: "))
    print("Area:", round(triangle_area(a, b, c), 2))
else:
    print("Bye!")

结构上的三个要点：每个函数只做一件事（单一职责）；菜单函数既打印又返回选择，把「读输入」与「决定流程」分开；主程序只负责调度，不写计算细节。三角形面积用海伦公式（Heron's formula）：半周长 s = (a+b+c)/2，面积 √(s(s−a)(s−b)(s−c))，开方用 ** 0.5。

docstring 放在函数第一行每个函数开头写一句 """Returns the area of a circle."""，既是注释又能被 help() 读出来（第 3 讲）。项目作业里评分的可读性就看这个。

九、常见错误与调试

print 当 return 用屏幕上有输出、调用处拿到 None。凡是题目要求「返回」，就只能 return；要同时看结果，在调用处 print 返回值。
参数个数不对TypeError: f() takes 2 positional arguments but 3 were given。数一遍 def 括号里的参数与调用括号里的值。
UnboundLocalError函数里既用又给某个变量赋值时，Python 把它当局部变量，于是「用」的那一步发现它还没赋值。解决办法：把值作为参数传进来，或在函数内先初始化。
只在函数里改了不可变参数，以为外面会变def inc(n): n = n + 1 改的是副本。要「改到外面」，得 return 新值并让调用处重新赋值：x = inc(x)。
常见误解

print() 只把文字显示在屏幕，不产生值；return 才交回值。函数只 print 不 return，调用处拿到 None（CodeGrade 报 The function should return a value 就是这个错）。另一个陷阱是可变默认参数：box=[] 只在定义时创建一次，多次调用共用；正确写法是默认 None，进函数再 if box is None: box = []。

推导补充

参数传递的差别来自可变性：不可变对象（数字、字符串）传进函数，改的是副本，外面不变；可变对象（列表、字典）传的是引用，改元素会反映到外面。由此推出设计原则——外部信息用参数传进来，别偷读全局变量，函数才独立可复用。判断 None 用 is None 而非 == None；函数必须先定义后调用。

例 1　写函数 count_vowels(s) 返回元音个数，并解释每一行的作用。

先按设计五问定好名称、输入、输出、判定、累加，再写代码。

def count_vowels(s):
    count = 0                  # 计数器：初值 0
    for ch in s.lower():       # 遍历每个字符，统一转小写
        if ch in "aeiou":      # 判定：是不是元音
            count = count + 1  # 命中就 +1
    return count               # 把结果交回调用者

print(count_vowels("Programming is fun"))
print(count_vowels("XYZ"))

输出：

5
0

解释：s.lower() 让大小写都算；ch in "aeiou" 是子串判断，比写六个 or 简洁；return 放在循环外面，循环结束后才返回总数——若缩进到循环里，函数会在第一个字符处就返回。

例 2　追踪 add_one 的执行，说明为什么 y 没有被改成 8。

先写出预期的中间值，再运行验证。函数：nr = nr + 1，return 2 * nr；调用 add_one(7)。

def add_one(nr):
    nr = nr + 1
    x = 2 * nr
    return x

x = 10
y = 7
print("returned:", add_one(y))
print("x and y now:", x, y)

输出：

returned: 16
x and y now: 10 7

逐步追踪：调用把 y 的值 7 复制给 nr；nr 变成 8；x（局部）是 16；返回 16。外面的 y 从未被赋值过，所以仍是 7；外面的 x 也是 10，因为函数里的 x 是另一个局部名字。

例 3　写 is_prime(n) 返回布尔值，并用它打印 20 以内的质数。

关键设计决策：返回 True / False，而不是打印「是质数」——这样调用者可以拿它做别的判断。

def is_prime(n):
    if n < 2:
        return False
    for d in range(2, n):
        if n % d == 0:
            return False
    return True

for n in range(2, 21):
    if is_prime(n):
        print(n, end=" ")

输出：

2 3 5 7 11 13 17 19

解释：n < 2 与「找到因子」两处都提前 return False，函数立刻结束；只有全部试完都没找到因子，才走到最后的 return True。把「判定」写成返回布尔值的函数，是让代码可复用的关键一步。

例 4　用两个函数改写面积计算器：circle_area(r) 与 triangle_area(a,b,c)，并在主程序里调用。

函数只负责算，主程序负责读输入与打印，职责分开。

def circle_area(r):
    return 3.14159 * r ** 2

def triangle_area(a, b, c):
    s = (a + b + c) / 2
    return (s * (s - a) * (s - b) * (s - c)) ** 0.5

r = float(input("Radius: "))
print("Circle area:", round(circle_area(r), 2))

a = float(input("Side 1: "))
b = float(input("Side 2: "))
c = float(input("Side 3: "))
print("Triangle area:", round(triangle_area(a, b, c), 2))

输入 2、3、4、5，输出：

Circle area: 12.57
Triangle area: 6.0

解释：圆面积 3.14159×4 = 12.56636 → 12.57；三角形三边 3、4、5 是直角三角形，面积 6，海伦公式给出 s=6、6×3×2×1=36、开方得 6。若三边构不成三角形（如 1、2、10），s−a 会为负，开方得到复数——真实程序应先校验三边关系。

  1. 写 max_of_three(a, b, c)，返回三者中的最大值（不许用 max()）。
  2. 写 count_char(s, ch)，返回 ch 在 s 中出现的次数（不许用 count()）。
  3. 写 is_even(n) 返回布尔值；再写一段代码，用它打印 1–10 中的偶数。
  4. 写 to_celsius(f) 把华氏温度转成摄氏温度（公式 C = (F − 32) × 5 / 9），返回保留一位小数的值。
  5. 把第 5 讲的「反复读成绩、输出平均分与及格人数」改写成函数 average(scores)，参数是一个分数列表。
答案与思路

1. 先假设 a 最大，再依次比较：best = a；if b > best: best = b；if c > best: best = c；return best。这是「找极值」模式，初值必须是列表里真实存在的元素，不能写 0（全负数时出错）。

2. count = 0，for c in s: if c == ch: count += 1，return count。若 ch 长度大于 1，这个写法按字符比会永远不相等——要按子串计数得用 s.count(ch) 或滑动窗口，题目限定单字符才有上面的简单解。

3. def is_even(n): return n % 2 == 0。函数体只有一行时，返回的就是这个布尔表达式，不必写 if。调用处：for i in range(1, 11): if is_even(i): print(i, end=" ")。

4. return round((f - 32) * 5 / 9, 1)。注意运算顺序：先减再乘除；写成 f - 32 * 5 / 9 会因为乘除优先而算错。

5. def average(scores): if not scores: return None（空列表要单独处理，否则 sum/0 报 ZeroDivisionError），否则 return sum(scores) / len(scores)。及格人数另写一个函数 count_passed(scores)，每个函数只做一件事。

必考def 定义、return 与 print 的区别、参数按位置传递、无 return 时得 None、局部变量的独立性。
易错 1　该 return 却 printCodeGrade 的 The function should return a value 就是这个。看到题目写「返回」，第一反应写 return。
易错 2　默认参数位置与可变默认值def f(a=1, b) 是语法错误；def f(box=[]) 会让所有调用共享同一个列表，必须改用 None 哨兵。
易错 3　把列表参数当成副本函数里 my_list[0] = 1000 会改到外面的列表。想保留原数据，调用前先 L[:] 复制（第 8 讲）或 list(L)。
进阶递归写法（函数调用自己）在阶乘、斐波那契里常见，但必须有终止条件；另外记住 return 一次只能返回一个对象，要返回多个值请用元组（第 8 讲）。

写函数之前，先回答五个问题

  • 默认参数只用于「可选」的尾部参数，且没有用可变对象
