学完本讲你能够：

  • 正确使用 + - * / // % ** 六种算术运算并说明优先级；
  • 用 == != < > <= >= 做比较，用 and or not 组合条件；
  • 用 input() 读入数据并显式转换；
  • 用 f-string 把变量嵌进字符串，控制小数位数与对齐。

1.1 优先级

从高到低：** → 一元负号 → * / // % → + -。同级从左往右。拿不准就加括号，这不是浪费时间。

例：2 + 3 * 4 ** 2 = 2 + 3 * 16 = 50。

二、布尔值与比较运算符

bool 只有 True 与 False。比较运算产生布尔值：

运算符含义
==等于（不是赋值 =）
!=不等于
< > <= >=小于 / 大于 / 小于等于 / 大于等于

字符串比较按字符编码逐位比："apple" < "banana" 为 True。

2.1 逻辑运算符

写法含义短路行为
a and b两者都真才真a 为假就不看 b
a or b有一个真就真a 为真就不看 b
not a取反—

优先级：not > and > or。所以 not a and b 等价于 (not a) and b。

区间判断数学的 0 < x < 10 在 Python 里可以直接写，等价于 0 < x and x < 10。

三、输入与输出

3.1 input()

input(提示文字) 会在终端显示提示并等待用户输入，返回的永远是字符串：

name = input("Your name: ")
age = int(input("Your age: "))

3.2 print()

print(a, b, sep=", ", end="\n")：sep 控制多个值之间的分隔符（默认空格），end 控制结尾（默认换行）。

print("a", "b")            # a b
print("a", "b", sep="-")  # a-b
print("no newline", end="")

四、f-string（推荐写法）

在字符串前加 f，用花括号嵌变量或表达式：

name = "Zishuo"
score = 87.456
print(f"{name} scored {score:.1f}")   # Zishuo scored 87.5
print(f"{score:8.2f}|")               # 宽度 8，保留 2 位："   87.46|"
print(f"{42:05d}")                    # 0042
print(f"{0.25:.1%}")                  # 25.0%
格式符含义
:.2f保留两位小数
:8.2f总宽 8，右对齐，两位小数
:<8 / :>8 / :^8左 / 右 / 居中，宽度 8
:05d整数，补零到 5 位
:.1%转百分比，一位小数
:,千分位分隔，如 1,234,567
必考把 {score:.2f} 写对是最常见的送分点，也是最常见的丢分点。花括号里冒号左边是值、右边是格式，顺序不能反。

常见误解

// 是向下取整不是截断：-7 // 2 = -4，而 int(-7/2) 得 -3；余数跟随除数符号，-7 % 2 = 1。另一个坑是 input() 永远返回字符串，age + 10 会拼接或报错，必须先转换。写 f"{score:.2f}" 时冒号左边是值、右边是格式，顺序不能反。

推导补充

优先级从高到低：** → 一元负号 → * / // % → + -，拿不准就加括号。and／or 有短路求值，name = input() or "anonymous" 能给出默认值。它们返回的是操作数本身而非布尔值：3 and 0 得 0，0 or 5 得 5；在 if 里非零当真，但赋值时拿到的是那个值。

例 1　已知半径 r 由用户输入，输出圆的面积（保留 2 位小数）。

解：r = float(input("r: "))，area = 3.14159 * r ** 2，print(f"Area = {area:.2f}")。注意先 float()，否则字符串不能做幂运算。

例 2　不借助 int() 打包，判断 137 是否为奇数，并输出各位数字之和。

解：奇数 → 137 % 2 == 1。各位和：137 // 100 = 1，137 // 10 % 10 = 3，137 % 10 = 7，合计 11。这是 // 与 % 的经典组合。

例 3　预测输出：print(1 if 5 > 3 else 2, not 0, 3 and 0)

解：5 > 3 为真取 1；not 0 为 True；3 and 0 返回 0（and 返回第一个假值）。输出 1 True 0。

参考答案与思路

1. a=int(input());b=int(input()) 然后 print(a//b, a%b)。除数为 0 时会抛 ZeroDivisionError。

2. print(f"{0.876:.1%}") → 87.6%。

3. 分别是 3、2、3。余数符号跟随除数（5 为正），所以 -17 % 5 = 3。

4. n % 2 == 0 and n > 10。也可写成 n > 10 and not n % 2。

必考四则与整除取余的计算结果预测、f-string 的格式符、input() 必须转换类型、逻辑运算符优先级。

易错= 与 == 混用；"5" + 5 的 TypeError；f-string 忘写前面的 f，结果原样打出花括号。

进阶and 与 or 返回的是操作数本身而非布尔值，所以可以写 name = input() or "anonymous"。

  1. 把所有 input() 的结果立刻包上 int() 或 float()；
  2. 写复杂表达式时先加括号，跑通后再考虑化简；
  3. 输出涉及小数就固定格式，不要让它打出 15 位；
  4. 比较浮点相等时用误差容忍，不要写 ==；
  5. 交作业前把每个 print 的期望值和实际值对一遍。
