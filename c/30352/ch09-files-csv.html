本节定位

前面所有程序的数据都只活到程序结束。这一讲让数据活下来：把结果写进文件，下次运行时再读回来。文件也是「批量数据」的入口——项目作业里的车辆、客户、交易，全都存在文本文件里。

技术上它把三件事合在一起：字符串处理（第 3 讲的 strip / split）、容器（第 8 讲的列表与矩阵）、循环（第 5 讲的逐行处理）。可以说这一讲是前面内容的第一次综合应用。

学完本讲你应当能够：

  • 说出文本文件与二进制文件的区别，并判断本课处理哪一类
  • 用 open 的三种模式打开文件，解释 w 为什么会清空内容
  • 用 readline 循环与 readlines 两种方式读文件，并处理行尾换行
  • 用 write / writelines 写文件，自行补 \n
  • 把 CSV 读成「列表的列表」，做筛选、追加与整体重写
  • 每个 open 都配上 close，并知道不关的后果

一、为什么需要文件

到现在为止，程序里的数据都活在内存里：程序一结束，变量、列表全部消失（Files p2）。要让数据「关机之后还在」，就得写进文件。文件（file）是存放在硬盘（HDD）或固态盘（SSD）上的一串数据。

课件把文件分成两大类（Files p3–p5）：

类别内容形式常见扩展名能否直接用文本编辑器改
文本文件 text file字符（ASCII / Unicode）.txt .csv .html .xml .py能
二进制文件 binary file原始字节.bin .exe .jpg .png .dat不能，需要专门软件

这门课只处理文本文件。判断依据很简单：能用记事本打开、能看懂，就是文本文件。文本文件按行组织，每行末尾有一个换行符 \n——这一点决定了后面所有读写细节。

课件的文件操作清单有五步（Files p6）：打开（读/写/追加）、读、写、追加、关闭。下面按这个顺序展开。

二、open()：打开文件并拿到句柄

打开文件的函数是 open(文件名, 模式)，返回值叫文件对象（file object）或文件句柄（file handle）（Reading p2）。它本身不装内容，只是「通向那个文件的一条通道」。

file = open("Example.txt", "r")
print(type(file))
<class '_io.TextIOWrapper'>

文件不存在时，读模式会直接报错：

file = open("example.txt", "r")
FileNotFoundError: [Errno 2] No such file or directory: 'example.txt'

注意文件名大小写敏感：Example.txt 与 example.txt 是两个不同的文件。Linux 与 macOS 上尤其明显，Windows 上虽然不区分，但代码里也不该靠这个巧合。

模式含义文件不存在时文件已存在时
"r"只读报 FileNotFoundError从头读
"w"只写新建空文件清空原有内容
"a"追加新建空文件保留内容，写在末尾
w 模式会清空文件这是最贵的一课：用 "w" 打开一个已有文件，内容立刻被抹掉，哪怕你一行都没写。只想加内容就用 "a"；只想读就别写。

三、读文件

3.1 readline()：一次一行

假设 Example.txt 有四行（课件原文）：

Hello, this is a sample text file.
It contains multiple lines of text.
Python can read this file.
This is the fourth line.

readline() 每次读一行，返回字符串，行尾的 \n 保留在字符串里；读到文件末尾后再调用，返回空字符串 ""（Reading p4）。

file = open("Example.txt", "r")
line1 = file.readline()
print(repr(line1))
line2 = file.readline()
print(repr(line2))
file.close()
'Hello, this is a sample text file.\n'
'It contains multiple lines of text.\n'

用 repr() 才能看见那个隐藏的 \n。直接 print(line1) 会看到「多一个空行」，因为字符串自带一个换行、print 又补一个。

3.2 用循环读到结尾

file = open("Example.txt", "r")
while True:
    line = file.readline()
    if line == "":
        break
    print(line.strip())
file.close()
Hello, this is a sample text file.
It contains multiple lines of text.
Python can read this file.
This is the fourth line.

line == "" 是「读完了」的信号，不是空行——空行读出来是 "\n"。这个区别在统计行数时非常关键。

3.3 strip()：去掉行尾换行与空白

strip() 去掉字符串两端的空白字符，包括空格、制表符、换行符（Reading p6）。读文件时几乎总要配它：

print(repr("  hello  \n".strip()))
print(repr("hello\n".strip()))
'hello'
'hello'

要小心 strip() 会去掉两端所有空白：如果数据本身前后有意义的空格（比如对齐的表格），就改用 rstrip("\n") 只去换行。

3.4 readlines()：一次读成列表

readlines() 把整个文件读成一个列表，每个元素是一行，仍然带着 \n；最后一行如果文件本身没有换行符，就不带（Reading p8）。

file = open("Example.txt", "r")
lines = file.readlines()
file.close()
print(len(lines))
print(repr(lines[0]))
print(repr(lines[-1]))
4
'Hello, this is a sample text file.\n'
'This is the fourth line.'

拿到列表后就能用第 8 讲的所有手段：len() 求行数、切片取前几行、循环处理。这也是 CSV 处理的标准起点。

3.5 read()：一次读完整个文件

课件最后提到「读取整个文件」（Reading p10）：read() 不带参数时返回一个包含全部内容的字符串。适合小配置文件；文件大时会把内存占满。

file = open("Example.txt", "r")
content = file.read()
file.close()
print(len(content))
print(content.count("\n"))
122
3

三个换行符对应四行——最后一行没有换行符。同一个文件也可以先 readlines() 再 read()，但第二次会得到空字符串，因为读写位置（文件指针）已经到末尾了。

四、写文件

用 "w" 打开就是写模式（Writing p2）：文件不存在会新建，已存在会被清空。写用 write()（写一个字符串）或 writelines()（写一个字符串列表）。

file = open("output.txt", "w")
file.write("First line\n")
file.write("Second line\n")
file.close()

write() 不会自动加换行，想让每行独立就必须自己写 \n。忘记加的后果是所有内容挤成一行。

lines = ["Alice,30\n", "Bob,25\n"]
file = open("output2.txt", "w")
file.writelines(lines)
file.close()

writelines() 同样不会补换行（Writing p5 专门强调）：列表里每个字符串该带 \n 就得带，否则会被首尾相连。它名字里的「lines」容易让人误以为会自动分行。

五、追加：a 模式

追加（append）是在文件末尾加内容，不动原有数据（Appending p2）。模式写 "a"，文件不存在时自动新建。

file = open("log.txt", "a")
file.write("This is the text to append.\n")
file.close()

连续运行三次，log.txt 里就有三行相同内容——这正是日志（log）的写法：程序每次运行追加一条，历史记录全部保留。

六、CSV：用逗号分列的文本

6.1 结构

CSV（comma-separated values）是用逗号分隔字段的文本文件（CSV p2）。每一行是一条记录，每个逗号前是一个字段；第一行通常是表头（header），也可能没有。

name,age,city
Alice,30,New York
Bob,25,Los Angeles
Charlie,35,Chicago

它在 Excel 里打开就是一张表，但本质仍是纯文本——所以用同样的 open + readlines 就能处理。

6.2 读 CSV：strip + split

课件的 read_csv.py 给出标准四步（CSV p6）：打开 → readlines → 关文件 → 逐行 strip().split(",") 装进列表。

file = open("people.csv", "r")
lines = file.readlines()
file.close()

data = []
for line in lines:
    row = line.strip().split(",")
    data.append(row)

print(data[0])
print(data[1])
print(len(data))
['name', 'age', 'city']
['Alice', '30', 'New York']
8

顺序不能反：先 strip() 去掉行尾 \n，再 split(",")；若先 split，最后一列会变成 'New York\n'（带换行）。得到的 data 是「列表的列表」，即第 8 讲的矩阵：data[i][0] 是第 i 行的姓名，data[i][1] 是年龄（仍是字符串）。

for row in data[1:]:
    if int(row[1]) > 28:
        print(row[0], "is", row[1])
Alice is 30
Charlie is 35

注意 row[1] 是字符串，比较大小或做算术前必须 int()，否则 "9" > "28" 会为真。

6.3 追加一行

file = open("people.csv", "a")
row = "Peter,52,Helsinki\n"
file.write(row)
file.close()

追加 CSV 就是把一整行拼成字符串写进去，末尾别忘 \n。字段里若本身含逗号（如地址），这种「手工拼」的写法就会错位——那种情况要用第 12 讲的 csv 模块。

6.4 删除一行（并说明示例中的隐患）

课件的 delete_from_csv.py 先全部读进内存，改完再整体写回：

file = open("people.csv", "r")
lines = file.readlines()
file.close()

data = [line.strip().split(",") for line in lines]

for line in data:
    if line[0] == "Eva":
        data.remove(line)

file = open("people.csv", "w")
for line in data:
    file.write(line[0] + "," + line[1] + "," + line[2] + "\n")
file.close()

思路是对的：读模式不能删，只能用写模式把「改好的全部内容」重写一遍。但边遍历边 remove 有隐患：删除后后面的元素整体前移，循环变量还按旧位置前进，于是紧跟在被删元素后的那一条会被跳过。这里只有一条 Eva 所以结果正确；要删多条就得遍历副本或重建列表。

safe = []
for row in data:
    if row[0] != "Eva":
        safe.append(row)

「筛选出要保留的，重建一个新列表」永远比「在列表里删」安全，值得养成习惯。

七、关闭文件与资源管理

每个 open 都必须配一个 close()（Files p6）。不关的后果：写入的内容可能还在缓冲区没落盘；文件被占用，别的程序改不了；程序开很多文件会耗尽句柄。

CodeGrade 会直接检查这一点（CG Guide 第 4.1.2 节）：反馈里出现 File not closed 就是忘了 close()；出现 Incorrect file mode 则是模式写错（该 "r" 写了 "w"）。

拓展：with 语句Python 还有 with open(...) as f: 的写法，离开缩进块时自动关闭文件，即使中途抛异常也会关。课程示例统一用 open / close，考试按课程写法即可；但在自己的项目里 with 更安全。

八、路径与编码

文件名可以写相对路径（"people.csv"，相对当前工作目录）或绝对路径（"C:/data/people.csv"）。IDLE 里运行时，当前目录通常是脚本所在目录；从别处运行时可能变，找不到文件的第一个排查点就是它。

Windows 路径里的反斜杠是转义字符（第 3 讲）："C:\temp\a.txt" 中的 \t 会被当成制表符。三种写法都可行："C:/temp/a.txt"（推荐）、"C:\\temp\\a.txt"、或原始字符串 r"C:\temp\a.txt"。

中文内容要保证编码一致：open(..., encoding="utf-8") 是明确写法。Windows 默认编码不一定是 UTF-8，读写含中文的文件时若出现乱码，先检查这一点（属拓展内容，课程示例未涉及）。

九、常见错误与调试

用 w 打开想读的文件内容瞬间被清空。规律：读用 r、写用 w、加内容用 a；不确定时先 r 读一遍看内容。
忘记 close 或忘记 \n不 close 可能丢数据、被 CodeGrade 判 File not closed；writelines 不补换行，忘记 \n 会全挤成一行。
strip 与 split 顺序颠倒先 split 会让最后一列带 \n，后续比较、转数字全部失败。固定写 line.strip().split(",")。
出问题先打印三件事打印 len(lines)、repr(lines[0])、repr(data[0])。绝大多数文件问题在这三个输出里就能看出来：行数不对、换行没去掉、切分错位。
常见误解

"w" 打开已有文件会立刻清空，哪怕一行没写——只想加内容用 "a"，只想读用 "r"。readline() 保留行尾换行，print(line) 会多一个空行，要配 strip()；write()／writelines() 都不自动补换行，忘记写换行就挤成一行。读 CSV 固定写 line.strip().split(",")，先 split 会让末列带换行。

前后衔接

这一讲是前面内容的首次综合：文件读进来是字符串（字符串讲），split 成列表、CSV 是列表的列表（容器讲），逐行处理靠循环。CSV 值全是字符串，算术前必须 int()，否则 "9" > "28" 为真。删多行别边遍历边 remove（前移会跳过下一条），改为重建新列表。每个 open 配 close，否则 CodeGrade 报 File not closed。

例 1　读取 Example.txt，输出行数、最长的一行及其长度。

用 readlines() 一次读入，再用第 8 讲的循环找最长行。比较长度前先 strip()，否则行尾的 \n 会算进长度。

file = open("Example.txt", "r")
lines = file.readlines()
file.close()

print("lines:", len(lines))

longest = ""
for line in lines:
    clean = line.strip()
    if len(clean) > len(longest):
        longest = clean

print("longest:", longest)
print("length:", len(longest))

输出：

lines: 4
longest: It contains multiple lines of text.
length: 35

解释：readlines() 得到 4 个元素；strip() 让每行去掉换行再比较；longest 初值用空串，因为任何行都比它长（若求最短行就不能这么初始化）。

例 2　把一组学生成绩写成 CSV 文件，再读回来计算平均分。

写的时候用 w 模式 + 手工拼行；读的时候用 strip().split(",")，数字列要 float()。

rows = [("Alice", 90), ("Bob", 75), ("Charlie", 60)]

file = open("scores.csv", "w")
file.write("name,score\n")
for name, score in rows:
    file.write(name + "," + str(score) + "\n")
file.close()

file = open("scores.csv", "r")
lines = file.readlines()
file.close()

total = 0
count = 0
for line in lines[1:]:
    parts = line.strip().split(",")
    total = total + float(parts[1])
    count = count + 1

print("average:", round(total / count, 1))

输出：

average: 75.0

解释：写文件时先写表头，再逐行写「姓名,分数」；str(score) 把数字变字符串才能拼接。lines[1:] 跳过表头；float(parts[1]) 把 '90' 变成数字。平均 (90+75+60)/3 = 75.0。

例 3　从 people.csv 中筛选出年龄大于 30 的人，输出姓名与城市。

先读到矩阵，再用两层下标取值；比较前把年龄转成整数。

file = open("people.csv", "r")
lines = file.readlines()
file.close()

data = []
for line in lines[1:]:
    data.append(line.strip().split(","))

for row in data:
    if int(row[1]) > 30:
        print(row[0], "-", row[2])

输出：

Charlie - Chicago
Frank - Miami

解释：lines[1:] 去掉表头；row[1] 是年龄字符串，int() 之后才能比大小；row[2] 是城市，本身含空格（New York）也不受影响，因为分割只看逗号。

例 4　把每次运行的时间戳追加到 log.txt，并说明为什么不能用 w 模式。

追加模式保留历史；w 会把之前的日志全部清空。

from datetime import datetime

stamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
file = open("log.txt", "a")
file.write(stamp + " program started\n")
file.close()

file = open("log.txt", "r")
lines = file.readlines()
file.close()
print("log lines:", len(lines))
print(lines[-1].strip())

第二次运行后输出（行数会随运行次数增加）：

log lines: 2
2026-11-20 02:53:16 program started

解释：strftime 把当前时间格式化成字符串（第 10 讲详讲）；"a" 让每次运行都往末尾加一条；读回来用 lines[-1] 看最近一条。若把 "a" 改成 "w"，行数永远是 1。

  1. 写程序统计 Example.txt 中一共有多少个单词（以空格分隔）。
  2. 把 1 到 5 的平方写成两列表头的 CSV 文件 squares.csv（数字,平方）。
  3. 读入一个文本文件，输出去掉空行后的行数。
  4. 把 people.csv 中所有人的年龄加一，写回一个新文件 people_new.csv（保留表头）。
  5. 解释并修正：f = open("a.txt", "w"); print(f.readline())。
答案与思路

1. 逐行 strip().split()（不带参数的 split() 按任意空白切），每行的 len() 累加。注意空行切出来是空列表，长度 0，不影响结果。

2. "w" 打开，先写 "number,square\n"，再循环 range(1, 6) 写 str(i) + "," + str(i * i) + "\n"，最后 close()。检查方法：用记事本打开看是否有 6 行。

3. 读所有行，if line.strip() != "": count += 1。关键是用 strip() 判断——只含 \n 的行 strip() 后是空串，而 line == "" 只匹配文件末尾。

4. 读 people.csv 得矩阵，表头原样写入新文件；数据行把 row[1] 转 int 加一，再拼回字符串写 people_new.csv。绝不能直接写回原文件——用 "w" 打开原文件会先把数据清空。

5. 两个错误："w" 模式不能读（应 "r"）；readline() 是文件对象的方法，用 print(f.readline()) 可以，但打开后马上清空了文件。正确写法是 "r" 打开、读完、close()。

必考r / w / a 三种模式的区别；readline 与 readlines 的返回形式；行尾 \n 与 strip()；CSV 的 strip().split(",")；必须 close()。
易错 1　w 模式清空文件想「读进来改一改再写回」，必须先把内容全读进内存、关掉文件，再用 w 重写。不能边读边写同一个文件。
易错 2　换行符处理print(line) 会多出空行（行自带 \n 加 print 的换行）；write() 不会自动换行。读写两侧的 \n 都要自己负责。
易错 3　相对路径 / 大小写FileNotFoundError 先查三件事：文件名拼写与大小写、当前工作目录、扩展名是否隐藏（Windows 默认隐藏扩展名，a.txt.txt 很常见）。
进阶with open(...) as f: 自动关闭；csv 模块能正确处理字段内含逗号与引号的情况（第 12 讲 DictReader）；大文件应逐行 readline 处理而不是 readlines 全读进内存。
