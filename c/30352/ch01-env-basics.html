这门课用 Python 3.13 从零开始。第一讲先把「工具装好、程序长什么样、数据怎么存」三件事解决掉，后面所有章节都建立在这三个概念上。

学完本讲你能够：

  • 安装 Python 3.13.7 与课程定制的 IDLE-Mod 编辑器，并跑出第一行输出；
  • 说清 Python 程序的执行顺序，用 print() 与注释把意图写明白；
  • 用变量保存数据，并区分 int / float / str / bool / None 五种基本类型；
  • 用 type() 查类型，用 int() / float() / str() 做显式转换。
为什么先学这个后面每一章都是「对某种类型的数据做某种操作」。分不清 "3" 和 3 就会遇到 TypeError，而 Python 的报错信息一多半来自类型不对。

一、安装与运行环境

1.1 安装 Python 3.13.7

  1. 到 python.org 下载 Windows installer (64-bit) 版 3.13.7；
  2. 安装界面上务必勾选 Add python.exe to PATH，不勾就得手动配环境变量；
  3. 选 Customize installation 时可以保持默认，但 pip 必须勾上；
  4. 装完在终端输 python --version，应回显 Python 3.13.7。

1.2 IDLE-Mod 编辑器

课程提供定制版 IDLE-Mod，它比官方 IDLE 多了运行按钮、代码补全与自动缩进。三条原则：一个文件一个程序（扩展名 .py）、保存到本课程文件夹、每改一行就 Ctrl+S。

注意Windows 上双击 .py 文件常常只是闪一下就没了。用 IDLE-Mod 的 F5 运行，或者在终端里先进到文件所在目录再 python 文件名.py，窗口才不会一闪而过。

1.3 程序的结构

一个 Python 程序就是一行行的语句（statement），从上往下依次执行。没有花括号，用缩进（indent，默认 4 个空格）表示层。注释用 # 开头，写给自己看：

# 计算两个数之和
a = 3        # 第一个加数
b = 5
print(a + b)  # 输出 8

二、变量 Variable

变量是「名字 + 值」的绑定。Python 不需要声明类型，赋值那一刻自动推断：

name = "Zishuo"
age = 20
height = 1.75
is_student = True

2.1 命名规则

  • 只能由字母、数字、下划线组成，且不能以数字开头；
  • 区分大小写：Age 与 age 是两个变量；
  • 不能用关键字（if、for、class、True 等）；
  • 习惯用小写加下划线：student_name、total_price。

四、类型转换 Type conversion

写法结果典型坑
int(3.9)3直接截断，不是四舍五入
int("42")42int("4.2") 会报 ValueError
float("3.5")3.5可转 "3" 也可转 "3.5"
str(42)"42"常用拼接："x=" + str(42)
bool(0)False0、""、None、空容器都是 False
易错"3" + 3 会报 TypeError: can only concatenate str (not "int") to str。要么 int("3") + 3，要么 "3" + str(3)。
常见误解

把变量想成“盒子”是后面类型错误的根源。Python 里变量是名字到值的绑定，赋值那刻才推断类型。"3" + 3 抛 TypeError，不是加号坏了，而是对两种类型没定义；要么 int("3") + 3，要么 "3" + str(3)。看到 TypeError 先查两边类型，别急着改运算符。

推导补充

两个坑来自“值”的性质。int(3.9) 是向零截断得 3，不是四舍五入；要舍入用 round()。0.1 + 0.2 != 0.3 是二进制浮点固有误差，比较写 abs(a-b) < 1e-9 而非 ==。假值判断：0、""、None、空容器都是 falsy，但 "0" 是非空字符串，为 True。

例 1　写出输出结果：print(7 // 2, 7 % 2, 7 / 2)

解：// 是整除取整数部分 → 3；% 取余 → 1；/ 永远是浮点除法 → 3.5。输出：3 1 3.5。

例 2　用户输入年龄，输出 10 年后年龄。

解：age = int(input("Age: ")) 把字符串转成整数，再 print(age + 10)。若忘写 int()，得到的是字符串拼接 "2010"，或者直接 TypeError。

例 3　判断下面哪些值是 False：0、"0"、""、None、[]、0.0

解：除 "0" 以外全是假值。"0" 是一个长度 1 的非空字符串，为 True。这是考试与调试中极高频率的坑。

参考答案与思路

1. print(int(3.7)) 或 print(3.7 // 1)，结果均为 3。

2. 只有 _tmp 与 total2 合法。2nd 数字开头，my-var 含减号，class 是关键字。

3. print(int("120") * 2) → 240。注意不能写 "120" * 2，那会得到 "120120"。

4. 二进制浮点无法精确表示 0.1、0.2，相加得 0.30000000000000004。比较浮点数应写 abs(a - b) < 1e-9。

必考// 与 / 的区别、% 的用法、int()/float()/str() 的转换、type() 判断类型。

易错input() 返回的永远是字符串；int("4.2") 会报错，要先 float() 再 int()。

进阶Python 3 的整数没有上限，可以算 2 ** 1000；浮点用 IEEE 754 双精度，15–16 位有效数字。

  1. 先想清楚要存什么类型的数据，再选 int / float / str / bool；
  2. 凡是来自 input() 的值，默认就是字符串，用前必须转换；
  3. 写完一行打印出来看一眼，确认类型与值都对；
  4. 看到 TypeError 先查两边的类型，而不是改运算符号；
  5. 变量名写完了能自己念一遍、别人能看懂，才算合格。
