本节定位

前三讲的程序是一条直线：从上到下，每行都执行。这一讲让程序第一次出现「分岔」——根据数据的真假决定走哪条路，其余路径直接跳过。这是控制结构（control structure）的起点，也是后面循环、函数里所有判断的基础。

上一讲把文本切开、拼好、印出去；这一讲用比较和逻辑运算把文本与数字变成 True / False，再交给 if 决定去留。下一讲用同样的布尔表达式控制循环。

学完本讲你应当能够：

  • 写出 == != < > <= >= 六种比较，并解释链式比较 x < y < 15
  • 用 and / or / not 组合条件，并说明短路求值的影响
  • 写出缩进正确的 if / if-else / if-elif-else，并解释块的边界
  • 根据取值范围设计互斥、顺序正确的 elif 链
  • 用 match-case 改写长 elif 链，并用 case _ 兜底

一、为什么需要分支

到目前为止，程序只有顺序结构：第 1 行、第 2 行……全部执行（if.pdf p2）。但现实充满选择：穿什么取决于天气，吃什么取决于忌口。程序也一样，需要「满足条件才做」。

控制结构（control structure）让执行顺序依赖数据。写法极其简单：

age = 20
if age >= 18:
    print("You are an adult.")
else:
    print("You are a minor.")

读法：if 后面是条件，条件为真执行缩进的那一块；else 后面是条件为假时执行的那一块。条件本身是一个布尔表达式（boolean expression），值只能是 True 或 False。

二、布尔表达式：比较运算符

2.1 六种比较

运算符含义例子（x = 5, y = 10）结果
==等于x == yFalse
!=不等于x != yTrue
>大于x > yFalse
<小于x < yTrue
>=大于等于x >= yFalse
<=小于等于x <= yTrue

== 是比较，= 是赋值，这两个符号永远不要写混。x = y 不会返回真假，它会把 y 的值塞进 x，然后 if x = y: 直接是语法错误。

2.2 链式比较

数学里的 0 < x < 10 在 Python 里可以直接写，等价于 0 < x and x < 10，而且中间那个 x 只计算一次：

x = 5
y = 10
print(x < y < 15)
print(0 <= x <= 5)
True
True

2.3 字符串比较

字符串按字符的编码逐位比较，本质上就是字典序（lexicographic order）。规则有三条：从左往右逐字符比，第一个不同的字符决定大小；前缀更短的更小（"ab" < "abc"）；大写字母排在小写字母前面（编码 65 起 vs 97 起）。

string1 = "hello"
string2 = "world"
print(string1 == string2)
print(string1 < string2)
print("Hello" < "hello")
print("apple" < "banana")
False
True
True
True

字符串不能和数字比大小（Example2 的最后一行）：

print("banana" > 5)
TypeError: '>' not supported between instances of 'str' and 'int'

原因是两种类型没有定义比较规则。想比「长度」必须先取 len()：len("banana") < 5 是 False。

2.4 浮点比较

浮点数在内存中是近似值（第 1 讲的数据类型、Extra reading 都提过），所以下面这行看起来该真、其实为假：

print(0.1 + 0.2)
print(0.1 + 0.2 == 0.3)
0.30000000000000004
False

判断两个浮点数「相等」要允许误差：abs(a - b) < 1e-9，或先把两边都 round(a, 5) 再比。

三、逻辑运算符

3.1 and / or / not

写法含义为真的条件
a and b并且a、b 都为真
a or b或者至少一个为真
not a取反a 为假
a = True
b = False
print("a and b:", a and b)
print("a or b:", a or b)
print("not a:", not a)
print("not False:", not False)
a and b: False
a or b: True
not a: False
not False: True

优先级从高到低是 not → and → or，比较运算符又高于它们。所以 not a and b 等于 (not a) and b；a == 1 or b == 2 and c == 3 等于 (a == 1) or ((b == 2) and (c == 3))。条件一复杂就加括号，读代码的人会感谢你。

3.2 短路求值

and 左侧为假时右边根本不看；or 左侧为真时右边也根本不看。这叫短路（short-circuit），Example4 用一个未定义的变量演示了它：

a = True
b = False
# c 未定义

print(a or c)   # True：左边已真，不再看 c
print(b and c)  # False：左边已假，不再看 c

# 下面两行会报 NameError，因为真的去看了 c
# print(b or c)
# print(a and c)

这解释了两件实用的事：一是 if x != 0 and 10 / x > 2: 不必担心除零，因为 x != 0 为假时右边被跳过；二是「先判断再访问」的写法是安全的。反过来，如果短路掩盖了本应暴露的错误，调试时会更难——这也是为什么 Example4 把会报错的两行注释掉而不是删掉。

and / or 返回的是操作数，不是 True/FalsePython 里 True and "x" 得 "x"，False or "y" 得 "y"，0 or 5 得 5。放在 if 里结果一样（非空串、非零数都当真），但如果把表达式结果直接赋给变量，拿到的是那个操作数。初学阶段建议条件里只放比较与逻辑运算，别依赖这个特性。

四、if 语句与缩进

4.1 语法骨架

基本语法（if.pdf p3）：if 关键字 → 条件 → 冒号 → 换行 + 缩进的块。

temperature = 20
if temperature > 15:
    print("It's warm outside!")

冒号表示「下面开始是这个 if 的块」。块内的行必须比 if 多缩进（通常 4 个空格），块在缩进退回时结束（if.pdf p6）。

4.2 缩进是语法，不是风格

别的语言用花括号 {} 划块，缩进只是好看；Python 直接用缩进定义块（if.pdf p4）。漏缩进会被判为「期望一个缩进块」：

if 5 > 2:
print("Five is greater than two!")
IndentationError: expected an indented block after 'if' statement on line 1

同一个块内缩进量必须完全一致（Example6）。下面这段第一行缩进 1 个空格、第二行缩进 8 个，Python 无法判断它们是否属于同一块：

if 5 > 2:
 print("Five is greater than two!")
        print("Five is greater than two!")
IndentationError: unexpected indent

还有两条实务规则：不要混用空格与 Tab——不同编辑器对 Tab 的宽度解释不同，切编辑器就会出错；IDLE 会在你回车时自动补上缩进，省事但也容易让人忘记检查层级。

4.3 块在哪里结束

缩进退回的那一行不属于 if 的块（Example7）：

i = 10

if i > 15:
    print("variable i is less than 15")
print("I am NOT in if")
I am NOT in if

条件为假，块内那行被跳过；没有缩进的 print("I am NOT in if") 与 if 无关，照常执行。顺带一提，示例里那句提示文字写反了（i 是 10，条件 i > 15 为假），这类「注释与代码不一致」的 bug 比语法错误更难发现——读代码时以代码为准。

五、if-else：二选一

写法（if_else.pdf p2）：条件为真走第一块，为假走 else 块，两块必有一块执行。

a = int(input("Enter an integer: "))
b = int(input("Enter another integer: "))

if a > b:
    print("The largest integer is", a)
else:
    print("The largest integer is", b)

输入 7 与 3，输出 The largest integer is 7。注意 input() 返回字符串，必须 int() 之后再比，否则比的是字典序（"10" < "9" 为真）。

六、if-elif-else：多选一

6.1 结构与执行规则

elif 是 else if 的缩写（if_else.pdf p4–p5）。执行顺序是从上往下逐个检查，第一个为真的块执行完，整个链条就结束，后面的 elif / else 全部跳过。

规则说明
只有一个块执行哪怕多个条件同时为真，也只走最上面那个
最多一个 else每个 if 链最多一个 else，且必须放最后
elif 可以有多个想排几个排几个，顺序即优先级
else 可以省略不需要兜底时省略，什么都不做
条件互斥靠你保证Python 不会替你检查区间是否重叠

6.2 顺序决定正确性

成绩等级的例子（if_else.pdf p6）是经典：

score = 85

if score >= 90:
    grade = 5
elif score >= 80:
    grade = 4
elif score >= 70:
    grade = 3
elif score >= 60:
    grade = 2
elif score >= 50:
    grade = 1
else:
    grade = 0

print("Grade:", grade)
Grade: 4

为什么能从大到小这么写？因为 85 已经满足了 >= 80，不会再往下看。如果把顺序写反（先判 >= 50），85 会命中第一条，直接得 1 分——这就是条件链最常见的逻辑错误：范围宽的放前面，后面的永远轮不到。

规则总结：判断区间时，要么按「从大到小」写 >=，要么按「从小到大」写 < 并让每条上界收紧，总之让条件互斥且覆盖全集。

6.3 一个完整的业务例子：运费

Example10 把订单金额映射到运费档位，结构与本讲完全一致：

order_value = float(input("Enter the total order value in EUR: "))

if order_value >= 100:
    shipping_cost = 0
elif order_value >= 50:
    shipping_cost = 5
elif order_value >= 20:
    shipping_cost = 10
else:
    shipping_cost = 15

print("The shipping cost for your order is " + str(round(shipping_cost, 2)) + " EUR.")

输入 63.5，输出 The shipping cost for your order is 5 EUR.。三个要点：float() 而不是 int()（金额有小数）；str() 把数字拼进字符串；边界值 100、50、20 都归入「较便宜」的一档，因为用的是 >=。

七、match-case：值匹配的更整齐写法

7.1 语法

match-case 是 Python 3.10 引入的（match_case.pdf p2），作用类似 C / Java 的 switch，用来替代一长串「同一个变量反复比较」的 elif。

status_code = 404

match status_code:
    case 200:
        print("OK")
    case 404:
        print("Not Found")
    case 500:
        print("Internal Server Error")
    case _:
        print("Unknown status code")
Not Found

下划线 _ 是通配符（wildcard），兜住所有没匹配上的值（match_case.pdf p3）。它等价于 else，但只能出现一次且习惯放最后。

7.2 一个 case 匹配多个值

用竖线 | 把多个候选写在一起（match_case.pdf p4）：

fruit = "banana"

match fruit:
    case "apple" | "banana" | "orange":
        print("This is a common fruit.")
    case _:
        print("This is not a common fruit.")
This is a common fruit.

可以匹配数字、字符串、布尔值。注意 | 是「或」，不是正则里的管道，两侧只能是字面量或模式，不能写表达式。

7.3 完整例子：博物馆开放时间

Kiasma_open.py 是课程给的完整练习：给定星期几，输出开放时间。

day = input("Give a day (Mon/Tue/Wed/Thu/Fri/Sat/Sun): ")

match day:
    case "Mon":
        print("Closed")
    case "Tue" | "Fri":
        print("Open 10-20")
    case "Wed" | "Thu":
        print("Open 10-18")
    case "Sat" | "Sun":
        print("Open 10-17")
    case _:
        print("There is no such day")

输入 Wed 输出 Open 10-18；输入 mon（小写）输出 There is no such day——match 是精确匹配，大小写敏感，所以用户输入最好先规范成 day.strip().capitalize() 或统一转小写后比较。

7.4 match 与 elif 链怎么选

场景推荐写法
同一个变量与若干固定值比较match-case，一眼看出分支表
比较范围（>=、<）if-elif，match 不适合区间
条件涉及多个变量if-elif
需要兜底分支两者都行：case _ 或 else

功能上 match 并不比 elif 强，它换来的是可读性；所以考试里两种写法都要会读、会改。

case 后面写裸变量名会「捕获」一切case day: 不是「当值等于变量 day 时」，而是「新建一个叫 day 的变量并匹配任何值」，于是后面的 case 永远轮不到。要比较变量，写 case "Mon": 这样的字面量，或先把候选值放进常量。_ 是唯一安全的通配符。

八、常见错误清单

把 == 写成 =if x = 5: 是语法错误；if x = 5 想表达的「判断相等」应写 ==。反过来 x == 5 单独一行只是算了个真假然后丢掉，不报错，也很难发现。
漏冒号if x > 5 后面没有冒号，报 SyntaxError: expected ':'。冒号是块的开场白，if / elif / else / for / while / def 全都要。
elif 顺序反了区间判断从宽到窄、从上到下必须单调；写成 >= 50 在前，高分也会掉进低档。写完用边界值（49、50、89、90）各测一遍。
把非空字符串当条件if "no": 恒为真，因为非空字符串为真。判断用户回答要写 if answer == "no":，不能只写字符串本身。
先画决策表再写代码把输入区间与期望输出列成两列，检查是否覆盖全集、是否重叠；然后照表写 elif，顺序自然正确。这比写完再调试快得多。
推导补充

if-elif-else 里顺序即正确性：第一个为真的分支执行完，整条链就结束。成绩若先判 >= 50，85 会命中第一条得 1；所以要么从大到小写 >=，要么从小到大收紧上界。互斥与覆盖全集要自己保证，Python 不检查重叠。浮点别直接比相等：0.1 + 0.2 == 0.3 为 False。

常见误解

缩进是语法不是风格：漏缩进抛 IndentationError，同块缩进量必须一致，别混用空格与 Tab。= 是赋值，== 才是比较。短路能防除零——if x != 0 and 10/x > 2 在 x 为 0 时右边不算。但 and／or 返回操作数：True and "x" 得 "x"，赋给变量时别当成布尔值。

例 1　输入一个整数，输出它是正数、零还是负数，并额外输出它的绝对值。

思路：先按「大于 0 / 等于 0 / 其余」三分支；绝对值用 abs()（第 2 讲的内置函数），不要手写两遍分支。

num = int(input("Enter a number: "))

if num > 0:
    print("Positive number")
elif num == 0:
    print("Zero")
else:
    print("Negative number")

print("Absolute value:", abs(num))

输入 -7，输出：

Negative number
Absolute value: 7

解释：三个分支互斥且覆盖全部整数；abs() 让「求绝对值」不必再写一个 if。注意这里用 int()，若允许小数要改 float()，但那样 num == 0 就要写成 abs(num) < 1e-9。

例 2　输入年份，判断是否闰年。

规则：能被 4 整除，但不能被 100 整除；或者能被 400 整除。把「或者」直接翻译成 or，把「但是」翻译成 and not。

year = int(input("Enter a year: "))

if (year % 4 == 0 and year % 100 != 0) or year % 400 == 0:
    print(year, "is a leap year")
else:
    print(year, "is not a leap year")

输入 1900 → 1900 is not a leap year；输入 2000 → 2000 is a leap year（被 400 整除）；输入 2024 → 闰年。

解释：括号不能省。and 优先级高于 or，这里刚好符合预期，但写清楚括号能让读者一眼确认分组。测试时至少覆盖 1900（例外）、2000（400 的例外之例外）、2024（普通闰年）、2023（普通平年）四个边界。

例 3　用 match-case 实现一个简易计算器：输入运算符与两个数，输出结果。

思路：用 case "+" 等字面量分支；除零要在分支里单独判，避免 ZeroDivisionError（第 11 讲会系统处理异常）。

op = input("Operator (+ - * /): ")
a = float(input("First number: "))
b = float(input("Second number: "))

match op:
    case "+":
        print(a + b)
    case "-":
        print(a - b)
    case "*":
        print(a * b)
    case "/":
        if b == 0:
            print("Cannot divide by zero")
        else:
            print(a / b)
    case _:
        print("Unknown operator")

输入 *、3、4 输出 12.0；输入 /、1、0 输出 Cannot divide by zero。

解释：match 只负责「选哪个运算符」，除数是否为零是分支内的二级判断——这种「外层匹配 + 内层条件」的嵌套在菜单类程序里非常常见。

  1. 输入三个整数，按从大到小输出（先比较再交换，不要用 sorted）。
  2. 输入百分制成绩，按 90/80/70/60/50 输出 5/4/3/2/1/0 等级，并处理「输入不在 0–100」的情况。
  3. 输入一个字符，判断它是大写字母、小写字母、数字还是其他（提示：可以用比较，也可以查第 2 讲的字符串方法）。
  4. 用 match-case 把 Kiasma 例子改成「输入小写也认」的版本。
  5. 输入 BMI 的两个分量（体重 kg、身高 m），按 <18.5 / 18.5–24.9 / 25–29.9 / >=30 输出四档结论。
答案与思路

1. 三个数排序的经典写法是三次两两交换：先让 a >= b（否则交换），再让 a >= c，最后让 b >= c。交换用 a, b = b, a（第 8 讲元组解包），本讲范围内也可用临时变量 t = a; a = b; b = t。

2. 先判合法性再判等级：if score < 0 or score > 100: print("Invalid")，否则接原来的 elif 链。这正是「先做守卫判断（guard clause）」的思路，比把非法值塞进等级链更清晰。

3. 用链式比较最直观：if "A" <= ch <= "Z": ... elif "a" <= ch <= "z": ... elif "0" <= ch <= "9": ...。也可以用 ch.isupper() / ch.islower() / ch.isdigit()（第 2 讲字符串方法）。注意 isdigit() 对空串返回 False。

4. 在读入后统一大小写：day = input(...).strip().capitalize()，这样 mon、MON、" Mon " 都变成 Mon，match 分支不用改。capitalize() 只把首字母大写、其余小写，正好匹配 Mon 形式。

5. bmi = weight / height ** 2，然后四档 elif，注意边界：<18.5、<25、<30、其余。用「上界递增」的写法保证互斥：if bmi < 18.5: ... elif bmi < 25: ...。

必考if-elif-else 的执行顺序与「只执行一个块」；缩进定义块；字符串比较的字典序；and/or 的短路；match-case 与 case _。

易错 2　漏冒号与缩进错误IndentationError 分两种：expected an indented block（该缩进没缩进）与 unexpected indent（不该缩进却缩了）。看错误行号，往上找它所属的 if。
易错 3　input 没转换就比大小input() 返回字符串，"9" > "10" 为真。比较数字前必须 int() / float()。
进阶浮点相等用 abs(a - b) < 1e-9；match 里裸变量名是捕获而非比较；and/or 返回操作数而非布尔值。这三点是判断题与改错题的常客。

操作清单

写 if 之前

  1. 把条件写成一句能判真假的话，例如「年龄大于等于 18」→ age >= 18
  2. 确认参与比较的两边类型一致：数字比数字、字符串比字符串
  3. 列出所有分支，检查是否互斥、是否覆盖全部情况
  4. 确定顺序：区间判断从宽到窄或从窄到宽，只能选一个方向
  5. 写完用边界值各测一次

缩进与语法自检

  • 每个 if / elif / else 行末都有冒号
  • 同一块内缩进量完全一致，没有混用 Tab 与空格
  • 块的结束靠缩进退回，退回后的语句不属于 if
  • == 用于比较，= 只用于赋值
  • 条件里没有写「永远为真」的非空字符串
