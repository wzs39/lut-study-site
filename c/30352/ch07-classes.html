本节定位

前六讲的数据都是「一个变量装一个值」，函数是「一段代码做一件事」。当一组数据要配上一组操作、还要被很多地方重复使用时，就需要类：把数据（属性）和行为（方法）打包成一个对象。

这一讲只讲最浅的一层——够读课件、够写项目作业里的 Car / Person / Transaction。真正的 OOP（继承、多态、封装）是另一门课的内容，本课不考。下一讲回到容器：列表、矩阵与元组。

学完本讲你应当能够：

  • 解释类与实例的关系，并说出「类是模板、对象是实例」
  • 写出带 __init__ 的类，用 self 把参数装成属性
  • 定义方法并用点号调用，读写的都是当前对象的属性
  • 创建多个实例，并说明它们的状态为什么互不影响
  • 把对象作为参数传给普通函数，在函数里调用它的方法
  • 认出漏写 self、__init__ 拼错、类属性误当实例属性这三类错误

一、面向对象：先摆正预期

课件第一句话很坦率：这是「回到 1980 年代的编程」（Chapter 6 Part 1 p2）。面向对象编程（object-oriented programming，OOP）本身是一门独立课程，这门课只讲最浅的一层——会定义类、会创建对象、会用对象的属性与方法。

核心比喻只有两个：类（class）是模板或模型，对象（object）是按模板造出来的东西，也叫实例（instance）。课件用汽车举例：Car 是类，Fiat 与 Audi 是它的实例；两者都是车，但各自有品牌、颜色、年份（Part 1 p3）。人也一样：Human 是类，Janne 是一个实例。

Python 是面向对象的语言，而且「一切皆对象」（Part 1 p4）：字符串、列表、整数都各自属于某个类。你早就在用对象了——"abc".upper() 里的 .upper() 就是字符串对象的方法。本讲只是学会自己造类。

二、四个术语

课件把术语压到四个（Part 2 p2–p4），这四个词必须能互相解释清楚：

术语英文解释中文说明
类 classA template that defines structure and behaviour.定义对象「有哪些数据、能做什么」的模板
对象 / 实例 object, instanceOne concrete thing created from the class.按模板造出来的具体个体
属性 attributeA variable stored in the object; its properties.对象自己的数据，如 brand、year
方法 methodA function defined inside the class.对象能执行的动作，如 start_engine()

课件给的属性例子是 age、year、size、weight、color、location；方法例子是 get_age()、start_engine()、calculate_distance()、close()、run()（Part 2 p4）。规律很清楚：属性是名词，方法是动词。

三、定义一个类

3.1 语法骨架

class ClassName:
    def __init__(self, parameters):
        self.attribute = parameters

    def method_name(self):
        # do something with self.attribute
        return something

三件事要注意：类名用首字母大写的驼峰写法（Car、Person、BankAccount），与函数的小写下划线区分开；class 行末有冒号；类里的所有方法都要缩进一层，而方法体再缩进一层。

3.2 构造函数 __init__ 与 self

__init__ 是特殊方法，叫构造函数（constructor）：创建对象时会被自动调用，用来把初始数据装进对象（Part 2 p6）。名字前后各有两个下划线，写错一个就退化成普通方法，创建对象时不会执行。

self 指「当前这个对象」。在类里访问自己的属性或调用自己的方法，都必须写 self.xxx。调用时 self 不用传，Python 自动把对象塞进去。

class Car:
    def __init__(self, brand, color, year):
        self.brand = brand
        self.color = color
        self.year = year

    def start_engine(self):
        print(self.brand + " says WROOM!")

car1 = Car("Tesla", "Black", 2019)
car1.start_engine()
Tesla says WROOM!

追踪一下 Car("Tesla", "Black", 2019)：Python 新建一个空对象；把对象作为 self、把三个实参依次给 brand、color、year；执行 __init__ 的函数体，把三个值挂到对象上；最后把对象交回给 car1。

3.3 点号访问

点号（dot notation）是「走进对象内部」的唯一入口（Part 2 p5）：对象.属性 读或写数据，对象.方法() 执行动作。

class Car:
    def __init__(self, brand, year):
        self.brand = brand
        self.year = year

car = Car("Skoda", 2012)
print(car.brand)
print(car.year)
car.year = 2015
print(car.year)
Skoda
2012
2015

最后一步说明属性是可写的：直接给 car.year 赋新值就行。想控制「怎么改」时，就写一个方法（如 update_year(new_year)），把规则集中在类里。

四、多个实例，各自独立

同一个类可以造出无数个对象，每个对象有自己的属性值——这是类与「一个装着数据的字典」最大的区别（Part 1 p3）。L6E1 造了两辆车：

class Car:
    def __init__(self, brand, color, year):
        self.brand = brand
        self.color = color
        self.year = year

    def start_engine(self):
        print(self.brand + " says WROOM!")

car1 = Car("Tesla", "Black", 2019)
car2 = Car("Skoda", "Grey", 2012)

print("car1 is of brand", car1.brand)
print("car2 is of brand", car2.brand)
car1.start_engine()
car2.start_engine()
car1 is of brand Tesla
car2 is of brand Skoda
Tesla says WROOM!
Skoda says WROOM!

car1 与 car2 是两个不同的对象：改 car1.year 不会影响 car2.year。方法里的 self 决定「操作哪一个对象」——car1.start_engine() 时 self 就是 car1。

五、完整的类：Person

课件的 L6E2 给出一个更完整的例子（Part 3 p2）：三个属性、五个方法，既有只读的 getter，也有修改状态的 updater，还有一个做判断的 is_adult()。

class Person:
    def __init__(self, name, age, country):
        self.name = name
        self.age = age
        self.country = country

    def get_name(self):
        return self.name

    def get_age(self):
        return self.age

    def get_country(self):
        return self.country

    def is_adult(self):
        return self.age >= 18

    def update_age(self, new_age):
        self.age = new_age

    def update_country(self, new_country):
        self.country = new_country

person1 = Person("Alice", 30, "USA")
person2 = Person("Pekka", 17, "Finland")

print(person1.get_name(), person1.get_age(), person1.get_country())
person1.update_country("Canada")
print(person1.get_country())
print(person2.get_name(), "adult?", person2.is_adult())
person2.update_age(18)
print(person2.get_name(), "adult?", person2.is_adult())
Alice 30 USA
Canada
Pekka adult? False
Pekka adult? True

读这段代码要注意三点：get_* 方法只是把属性值交出去，没有副作用；update_* 方法改的是 self.age，所以改完之后同一个对象的后续查询会看到新值；is_adult() 把判断规则写在类里，外部调用者不必知道「18 岁」这个阈值。

六、对象作为参数

对象可以像普通值一样传给函数。L6E2 的后半段定义了一个普通函数，参数是一个 Person 对象：

def can_buy_alcohol(human):
    if human.is_adult():
        print(human.get_name() + " can buy alcohol in Finland")
    else:
        print(human.get_name() + " cannot buy alcohol in Finland")

can_buy_alcohol(person2)
Pekka cannot buy alcohol in Finland

函数里直接调用 human.is_adult()：它不关心对象内部有几个属性，只依赖对象「会做什么」。这就是把数据与行为放在一起的好处——调用方代码更短，规则变化时只改类。

七、类、字典、函数：什么时候用哪个

需求推荐做法原因
只是把几个字段捆在一起传字典 {"brand": "Ford", "year": 2015}第 12 讲；轻量、可直接打印、适合读 JSON
一组数据要配上一组操作，且要被多处复用类属性和方法绑在一起，调用方只需知道接口
纯计算，不保存状态普通函数最简单，不必造对象

课件的项目作业（汽车租赁系统）里，车辆、客户、交易都是「一条记录 + 若干操作」，用字典列表也能做，用类会更整齐。考试两种都可能出现，读得懂就行。

八、类属性与实例属性

课件没有展开这一点，但它是最容易「看起来能跑、其实错了」的地方。写在 __init__ 里、带 self. 的是实例属性，每个对象一份；直接写在类体里的（不带 self.）是类属性，所有对象共享。

class Car:
    wheels = 4                      # 类属性：所有实例共享

    def __init__(self, brand):
        self.brand = brand          # 实例属性：每个对象一份

a = Car("Tesla")
b = Car("Skoda")
a.wheels = 3                        # 这一步新建了 a 自己的属性

print(a.wheels, b.wheels, Car.wheels)
print(a.brand, b.brand)
3 4 4
Tesla Skoda

读 a.wheels 时，先找实例属性，找不到才去类里找；给 a.wheels 赋值只影响 a，于是出现 3 4 4。如果写的是 Car.wheels = 3，三个输出就都变 3。初学阶段建议所有属性都写进 __init__，避免这种歧义。

九、检查对象里到底有什么

调试类的问题，第一步永远是「属性到底装上了没有」。三种看法：

class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

p = Person("Alice", 30)
print(p.__dict__)          # 所有实例属性
print(type(p).__name__)    # 类名
print(isinstance(p, Person))  # 是不是这个类的实例
{'name': 'Alice', 'age': 30}
Person
True

p.__dict__ 直接把属性表打出来，比逐个猜快得多：里面少了哪个属性，就说明 __init__ 里漏了对应的 self.xxx = ...。

十、常见错误与调试

忘记写 self定义方法时写成 def start_engine():，调用 car.start_engine() 会抛 TypeError: start_engine() takes 0 positional arguments but 1 was given——那个多出来的实参就是自动传入的对象。
__init__ 拼错写成 __int__、_init_ 或 init，创建对象时不会执行，属性全部不存在，之后访问 car.brand 抛 AttributeError。前后各两个下划线，一个都不能少。
属性赋值漏了 self.在 __init__ 里写 brand = brand，只是创建了一个局部变量，对象上没有这个属性。必须是 self.brand = brand。
直接打印对象只看到地址print(car) 输出 <__main__.Car object at 0x...>，因为默认没有「怎么显示自己」的规则。要看内容请打印具体属性，或在类里定义 __str__（属拓展内容，考试不要求）。
设计类先列名词与动词把需求里的名词挑出来当属性（brand、year、price），动词挑出来当方法（start、update、is_adult）。列不出来说明这个类还不该存在。
常见误解

方法漏写 self，调用 car.start_engine() 会抛 TypeError——那个多出来的实参就是 Python 自动传入的对象。__init__ 前后各两个下划线，拼成 __int__ 就退化成普通方法，之后访问属性抛 AttributeError。在 __init__ 里写 brand = brand 只创建局部变量，必须是 self.brand = brand。

前后衔接

类是数据 + 行为的打包：属性是名词（brand、year），方法是动词（start、is_adult）。多个实例各自独立，self 决定操作哪一个对象。把对象传给普通函数，函数只调用 human.is_adult()，不关心内部属性，规则变化时只改类。调试第一步看属性装没装上：p.__dict__ 直接打出属性表，缺哪个就回 __init__ 补。

例 1　定义 Car 类（品牌、颜色、年份 + 启动方法），创建两辆车并输出品牌。

这是课件 L6E1 的完整结构：构造函数装数据，方法用数据。

class Car:
    def __init__(self, brand, color, year):
        self.brand = brand
        self.color = color
        self.year = year

    def start_engine(self):
        print(self.brand + " says WROOM!")

car1 = Car("Tesla", "Black", 2019)
car2 = Car("Skoda", "Grey", 2012)

print(car1.brand, car1.color, car1.year)
print(car2.brand, car2.color, car2.year)
car1.start_engine()
car2.start_engine()

输出：

Tesla Black 2019
Skoda Grey 2012
Tesla says WROOM!
Skoda says WROOM!

逐点解释：Car("Tesla", "Black", 2019) 自动调用 __init__，三个值分别挂到 self.brand、self.color、self.year；两个实例互不影响；start_engine 里用 self.brand 取当前对象的品牌，所以同一段代码对两辆车输出不同文字。

例 2　给 Person 类加一个 birthday() 方法，使年龄加一，并验证对象状态确实变了。

修改状态的方法要直接写 self.age = self.age + 1，调用后同一个对象再查询就能看到变化。

class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def birthday(self):
        self.age = self.age + 1

    def is_adult(self):
        return self.age >= 18

p = Person("Pekka", 17)
print(p.name, p.age, p.is_adult())
p.birthday()
print(p.name, p.age, p.is_adult())

输出：

Pekka 17 False
Pekka 18 True

解释：birthday() 没有参数（除 self），也不返回值——它的作用是改状态。这类「只做副作用、不返回值」的方法很常见，调用后要重新读属性来确认效果。

例 3　写一个 BankAccount 类，支持存款、取款、查余额；取款金额超过余额时拒绝并给出提示。

把规则写进方法里，调用方就不必自己判断——这是类相对「裸字典」的优势。

class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        self.balance = self.balance + amount

    def withdraw(self, amount):
        if amount > self.balance:
            print("Insufficient funds")
        else:
            self.balance = self.balance - amount

    def show(self):
        print(self.owner, "balance:", self.balance)

acc = BankAccount("Alice", 100)
acc.deposit(50)
acc.withdraw(500)
acc.withdraw(30)
acc.show()

输出：

Insufficient funds
Alice balance: 120

解释：初始 100，存 50 得 150；取 500 被拒绝，余额不变；取 30 得 120。注意 __init__ 的 balance=0 是默认参数（不可变对象，安全），可以 BankAccount("Bob") 只给名字。

  1. 定义 Rectangle 类（宽、高），带 area() 与 perimeter() 两个方法。
  2. 给 Person 类加一个 greet() 方法，输出 Hi, I am NAME。
  3. 定义 Student 类（姓名、学号、成绩列表），加方法 average() 返回平均分。
  4. 写 Counter 类，有 increment() 与 value() 两个方法，模拟一个计数器。
  5. 把第 5 讲的乘法表程序改写成 MultiplicationTable 类，方法 show(n) 打印 n 行。
答案与思路

1. __init__(self, w, h) 存两个属性；area 返回 self.w * self.h；perimeter 返回 2 * (self.w + self.h)。测试 Rectangle(3, 4)：面积 12、周长 14。

2. def greet(self): print("Hi, I am " + self.name)。用「方法内部拼接」而不是返回值，是因为要求是「输出」；若题目说「返回问候语」，就得写 return（第 6 讲的区别）。

3. average 里要防零：if not self.grades: return 0，否则 sum / 0 抛异常。成绩列表是可变对象，直接存引用即可，但若担心外部改动，可在 __init__ 里写 self.grades = list(grades)。

4. __init__ 里 self.count = 0；increment 里 self.count += 1；value 返回 self.count。三次 increment() 后 value() 应为 3。

5. 方法 show(self, n) 里用双重循环：外层 range(1, n + 1)，内层 range(1, i + 1)，内层 print(..., end="\t")，外层结束后 print()。类在这里只是「把数据和操作打包」的容器，循环逻辑与第 5 讲完全相同。

必考类与实例的区别；__init__ 自动调用；self 的含义与省略规则；属性与方法的点号访问；多个实例状态独立。
易错 1　方法忘记 self定义时 def f(): 而调用 obj.f() 会多传一个实参，报 TypeError。类里所有实例方法第一个参数都写 self。
易错 2　属性写在类里而不是 __init__ 里在类体里直接写 brand = "Tesla" 是类属性，所有实例共享；要每个对象一份，必须写 self.brand = ...。两者读起来都能 obj.brand，但改一个会影响全部，非常隐蔽。
易错 3　__init__ 名字拼错少了任一端的双下划线就不会被自动调用，属性不存在，随后 AttributeError。写完先 print(obj.__dict__) 看属性有没有装上。
进阶__str__ 可以自定义 print(obj) 的内容；isinstance(obj, Car) 可以判断类型。两者都超出本课考点，但读课件之外的代码时会遇到。

操作清单

定义类之前

  1. 列出需求里的名词 → 这些是属性
  2. 列出需求里的动词 → 这些是方法
  3. 确认哪些数据必须「每个对象一份」→ 写进 __init__ 并用 self.
  4. 确认哪些规则应该由类自己守 → 写成方法，而不是让调用方判断

写完后的检查

  • 类名首字母大写，__init__ 前后各两个下划线
  • 每个方法第一个参数都是 self
  • 所有属性赋值都写了 self.
  • 创建对象时实参个数与 __init__ 的参数（不含 self）一致
  • 打印对象时输出的是属性而不是 <... object at 0x...>
