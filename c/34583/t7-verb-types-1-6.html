本节定位

第七讲是全课程语法密度最高的一讲：把芬兰语六类动词的识别、词干推导、肯定与否定变位一次讲完。前六讲只用到第一类（-a/-ä）与零散的第二、三、四类形式（juoda、tulla、halata），这一讲把它们整理成一张可查的表。

材料明确写了三件事：类型按不定式结尾判定；每一类有固定的去尾加词尾规则；第三、四类要特别注意辅音交替的方向与第一类不同。把这三件事记牢，遇到生词也能现场推出变位。

学完本节你应当能够：

  • 看到任意不定式，在 5 秒内判出它属于六类中的哪一类
  • 按类型规则推导词干，并写出六个人称的肯定形式
  • 写出六类动词的否定式，并说明为什么否定式只用一个词干
  • 解释第三、四类的交替方向与第一类「hän/he 强级」的差别
  • 处理 olla、mennä、nähdä、tehdä 等高频不规则动词

7.1 为什么要分类型：识别靠结尾

芬兰语动词不能像英语那样「加 -s / -ed」通用处理，因为不同结尾的动词要去掉不同的尾巴。材料的分类标准只有一条：看不定式最后几个字母。

类型不定式结尾代表动词
第 1 类-a / -ä（前面是元音）lukea, puhua, sanoa, ostaa, kirjoittaa, kysyä, yrittää, tietää, ymmärtää
第 2 类-da / -däsaada, juoda, tuoda, jäädä, tupakoida, syödä, luoda, imuroida
第 3 类-la/-lä, -ra/-rä, -na/-nä, -sta/-stäolla, tulla, ajatella, kävellä, panna, mennä, surra, nousta, ratkaista, opiskella, kuunnella, pestä
第 4 类-ata/-ätä（也有 -uta, -ota, -eta, -itä）avata, pelata, tavata, luvata, määrätä, kadota, halata, herätä, siivota
第 5 类-ita/-itätarvita, valita, mainita, häiritä, hallita, merkitä
第 6 类-eta/-etä（罕用）vanheta, kylmetä, paeta, suureta, kyetä

判断时的顺序很重要：先看是不是 -da/-dä（第 2 类），再看是不是 -sta/-stä（第 3 类），然后才看 -ta/-tä（第 4、5、6 类的分界）。因为 nousta 结尾是 -sta，属第 3 类，不能误判成第 4 类。

区分第 4、5、6 类-ita/-itä 前面通常是单元音 i（tarvita、valita、häiritä）→ 第 5 类；-eta/-etä 表示「变成……」（vanheta、kylmetä、paeta）→ 第 6 类；其余 -ata/-ätä（前面是 a/ä 或辅音）→ 第 4 类。

7.2 词干推导规则

材料对每一类都给了「Sääntö」（规则），可以直接抄成操作指令：

类型规则例：不定式 → 词干
第 1 类去掉 -a / -äpuhua → puhu；yrittää → yritä
第 2 类去掉 -da / -däjuoda → juo；syödä → syö
第 3 类去掉 -la/-lä、-ra/-rä、-na/-nä、-sta/-stä，再加 -etulla → tule；mennä → mene；nousta → nouse
第 4 类去掉 -ta / -tä，再加 -a / -ähalata → halaa；herätä → herää；tavata → tapaa
第 5 类去掉 -a / -ä，再加 -setarvita → tarvitse；valita → valitse
第 6 类去掉 -ta / -tä，再加 -nevanheta → vanhene；kylmetä → kylmene

第 3 类的「加 -e」是本讲最容易被忽略的一步。以 tulla 为例：去掉 -la 得 tul，加 -e 得 tule-，然后加人称词尾得 tulen, tulet, tulee, tulemme, tulette, tulevat。如果不加 -e，就会写出 tuln 这种不存在的形式。

第 4 类的「加 -a/-ä」同样容易漏：halata 去掉 -ta 得 hala，再加 -a 得 halaa-，故 halaan（我拥抱）。只写 halan 是错的。

7.4 否定式：六类共用一套规则

材料把否定式的做法与肯定式并列给出，结论是六类完全一样：ei 的变位形式 + 词干。也就是说，只要词干推对了，否定式不需要额外规则。

类型词干否定（minä）否定（hän）否定（he）
1 puhuapuhuen puhuei puhueivät puhu
2 juodajuoen juoei juoeivät juo
3 tullatuleen tuleei tuleeivät tule
4 halatahalaaen halaaei halaaeivät halaa
5 tarvitatarvitseen tarvitseei tarvitseeivät tarvitse
6 vanhetavanheneen vanheneei vanheneeivät vanhene

否定动词的六个人称：en, et, ei, emme, ette, eivät。这是唯一需要死记的否定词形组，且与第 5 讲一致。

材料还特别给了第 4 类的否定示范：halata → halaa，故 en halaa, et halaa, ei halaa, emme halaa, ette halaa, eivät halaa；kerrata → kertaa，故 en kertaa 等。注意这里否定式与第一人称肯定式同形（halaan 与 halaa 只差一个 n），不要混。

7.5 反向交替：第三、四类的特别注意

材料在两处加了同一句提醒：Muista käänteinen astevaihtelu! Infinitive is weak (heikko), conjugation strong (vahva)（记得反向交替！不定式与变位的强弱关系与第一类相反）。它的实际含义是：第三、四类的强级出现在不定式本身，变位形式反而取弱级；而第一类恰好相反，强级只留给 hän 与 he。

类型不定式形态变位形态（第一 / 第三人称）强弱关系
第 1 类 nukkuanukkua（kk）nukun（k）/ nukkuu（kk）强级只在 hän/he
第 3 类 tullatulla（ll）tulen（l）/ tulee（l）强级在不定式，变位取弱级
第 3 类 noustanousta（st）nousen（s）/ nousee（s）同上
第 3 类 mennämennä（nn）menen（n）/ menee（n）同上
第 4 类 herätäherätä（t）herään（无 t）/ herää（无 t）变位丢失 t，等同弱化
第 4 类 tavatatavata（v）tapaan（p）/ tapaa（p）变位反而出现强级 p

为什么会有这种差别？因为第一类的词干在不定式里看不到交替信息（nukkua 的 kk 只在词干内部），要靠人称词尾的音节结构判断强弱；而第三、四类的不定式结尾本身就含交替对（-lla、-sta、-ta），去掉词尾时交替已经发生，变位形式直接继承交替后的结果。

实用建议不要试图用一条公式推出所有交替。正确做法是：按规则推词干，遇到 K/P/T 就查例词表。材料给的 tulla / ommella / mennä / nousta / pestä / surra / panna / ajatella 八个第三类例子基本覆盖了常见交替。

7.7 分类练习的解题流程

材料的配对作业给了一串动词要求归入六类：HÄIRITÄ, HALATA, SYÖDÄ, UNOHTAA, SUURETA, ASUA, NOUSTA, HERÄTÄ, PELATA, TARVITA, TUODA, SANOA, PANNA, TUPAKOIDA, LAKATA, KANTAA, YMMÄRTÄÄ, SURRA, VANHETA, VALITA, VISKATA, OSTAA, KÄVELLÄ, KYETÄ, RAKASTAA, HALLITA, LYÖDÄ, OPISKELLA, JUODA, PAETA, MERKITÄ, PURRA, SIIVOTA, PESTÄ, PUHUA, LUODA。

  1. 读结尾：-da/-dä → 第 2 类（syödä, tuoda, juoda, lyödä, luoda, tupakoida）
  2. 结尾 -sta/-stä → 第 3 类（nousta, pestä）；-la/-lä、-ra/-rä、-na/-nä → 第 3 类（olla 类、surra、purra、panna）
  3. 结尾 -ita/-itä → 第 5 类（häiritä, tarvita, valita, hallita, merkitä）
  4. 结尾 -eta/-etä → 第 6 类（suureta, vanheta, paeta, kyetä）
  5. 其余 -ata/-ätä、-ota、-uta → 第 4 类（halata, herätä, pelata, lakata, viskata, siivota）

注意几个容易误判的：unohtaa 结尾是 -aa（第一类）；kantaa 也是第一类；opiskella、kävellä 是第三类；sanoa、asua、ostaa、rakastaa、puhua 是第一类。

高频错误 1把 tarvita 当第四类：en tarvia 错，应为 en tarvitse。
高频错误 2第三类忘加 -e：en tul、hän tullee 都错。
考试策略变位题先写「类型 + 词干」两个标注，再写六个形式。即使某个形式写错，标注正确也能拿到步骤分。
前后衔接

六类动词按不定式结尾判型：1 类 -a/-ä（puhua）、2 类 -da/-dä（juoda）、3 类 -la/-na/-ra/-sta（tulla, mennä, nousta）、4 类 -ata/-ätä（halata, tavata）、5 类 -ita/-itä（tarvita）、6 类 -eta/-etä（vanheta）。词干推导各有一步易漏：3 类去尾后加 -e（tulla→tule-，否则会造出 tuln），4 类去 -ta 后加 -a/-ä（halata→halaa-），5 类加 -se（tarvita→tarvitse-），6 类加 -ne。第三人称单数形态因类而异：1、4 类拉长元音（puhuu, halaa），2 类不加长（juo），3、5、6 类用 -ee（tulee, tarvitsee, vanhenee）。否定式六类通用 ei + 词干。交替方向要分清：第一类强级在 hän/he，第三、四类相反——不定式强、变位弱（nous(a)→nousen，st→s）。高频不规则 olla→olen/on/ovat、tehdä→teen/tekee、nähdä→näen/näkee 需整块记。

拓展深化 7.5 芬兰语动词六大变位族（Verbit 1–6）底层词干提取算法与辅音交替逆向定理

【拓展深化】动词词干提取算法与弱强阶逆向演化规律

系统剖析 1~6 型动词词干的元音/辅音脱落算法，破解 3/4/6 型动词为什么原形处于弱阶而变位后进入强阶的逆向交替之谜。

动词变位常被视为庞杂的特例记忆，但在生成语言学框架下，动词 1 型为正向交替（原形强阶 → 人称弱阶），而动词 3/4/6 型则遵循逆向交替（原形弱阶 → 人称强阶）。掌握底层词干提取算法即可实现通解：

2 型-DA/DÄ脱落后缀 -da/-dä无交替（辅音稳定）syödä → syö-, juoda → juon

例 1　判断并变位：opiskella（学习）属于哪一类？写出六个人称。

解：结尾 -lla，属第 3 类。去 -la 加 -e 得词干 opiskele-。六个人称：opiskelen, opiskelet, opiskelee, opiskelemme, opiskelette, opiskelevat。

交替：ll → l，所以变位形式只有一个 l，不定式有两个 l。否定：en opiskele。

例 2　把 tavata 与 herätä 变位，并说明两者交替方向为何不同。

解：tavata（第 4 类）→ 词干 tapaa-：tapaan, tapaat, tapaa, tapaamme, tapaatte, tapaavat，其中 v → p 是「变位出现强级」。herätä（第 4 类）→ 词干 herää-：herään, heräät, herää, heräämme, heräätte, heräävät，其中 t 完全消失。

说明：同类动词也可能走向不同方向，所以第 4 类的交替必须按词记。材料用 halata → halaan、kerrata → kertaan 两组示范了「丢 t」与「rr → r」两种。

例 3　判断对错：Hän ei tarvitse 与 Hän ei tarvitsee；He ei opiskele。

解：第一组 Hän ei tarvitse 正确，否定式用词干，不加第三人称的元音延长（tarvitsee 是肯定式）。第三句错在 ei：he 对应 eivät，应为 He eivät opiskele。

核心：否定式只有两层结构——否定词负责人称，主动词只负责词干。任何「主动词也变人称」的写法都错。

例 4　把「我们明天不去学校，我们在家学习」译成芬兰语。

解：Huomenna me emme mene kouluun, me opiskelemme kotona.

核对：mennä 第三类，否定 emme mene；opiskella 第三类，肯定 me 形式 opiskelemme；kouluun 是 illative（去某处）；kotona 是 essive（在家，固定说法）。

  1. 判断类型并写出词干：puhua、juoda、mennä、halata、tarvita、vanheta、nousta、valita、paeta、siivota。
  2. 变位 tulla、tarvita、vanheta 的六个人称（肯定与否定各一组）。
  3. 改错：Minä tarvia apua. / Hän ei tul. / He ei puhu. / Me opiskellemme.
  4. 翻译：「他不会说芬兰语，但他每天都在学。」
  5. 从材料配对作业里选 12 个动词，按六类分组（每类至少一个）。
答案与思路

1. puhua（1，puhu-）、juoda（2，juo-）、mennä（3，mene-）、halata（4，halaa-）、tarvita（5，tarvitse-）、vanheta（6，vanhene-）、nousta（3，nouse-）、valita（5，valitse-）、paeta（6，pakene-）、siivota（4，siivoa-）。

2. tulla：tulen / tulet / tulee / tulemme / tulette / tulevat；en / et / ei / emme / ette / eivät tule。tarvita：tarvitsen / tarvitset / tarvitsee / tarvitsemme / tarvitsette / tarvitsevat；en tarvitse 等。vanheta：vanhenen / vanhenet / vanhenee / vanhenemme / vanhenette / vanhenevat；en vanhene 等。

3. tarvia → tarvitsen；ei tul → ei tule；He ei puhu → He eivät puhu；opiskellemme → opiskelemme。

4. Hän ei puhu suomea, mutta hän opiskelee sitä joka päivä. 注意 sitä 是 se 的部分格（指代 suomea）。

5. 示例：1 类 puhua、ostaa；2 类 juoda、tuoda；3 类 mennä、nousta；4 类 halata、herätä；5 类 tarvita、valita；6 类 vanheta、paeta。

必考六类识别 + 词干推导 + 六人称变位 + 否定式。变位填空（如 PILATA、mennä、ostaa）是本课程最固定的题型。
易错 1第三类忘加 -e、第四类忘加 -a：en tul、hän hala。
易错 2把 -sta 结尾的动词判成第四类：nousta 是第三类。
易错 3olla 的 hän / he 形式：on、ovat，既不延长也不加 -vat。
进阶能用「不定式结尾本身含交替信息」解释第三、四类为何与第一类方向相反，而不是死记例词。

六类动词操作清单

判类型三步

  1. 先查 -da/-dä → 第 2 类
  2. 再查 -la/-lä、-ra/-rä、-na/-nä、-sta/-stä → 第 3 类
  3. 然后按 -ita（5 类）、-eta（6 类）、-ata（4 类）、其余 -a/-ä（1 类）分流

写形式三步

  1. 按类型规则得词干（第 3 类加 -e，第 5 类加 -se，第 6 类加 -ne，第 4 类加 -a/-ä）
  2. 加人称词尾：n / t / 长元音或 -ee / mme / tte / vat-vät
  3. 否定式只留词干，人称交给 en / et / ei / emme / ette / eivät
