本节定位

第六讲把动词与词汇接到「生活内容」上：你喜欢什么、小时候练过什么、以后想学什么。语法上它引出两条重要线索——harrastaa 后面接部分格宾语，以及把动作变成名词（elokuvan katsominen、musiikin kuuntelu）。

这一讲还第一次出现完成体形式 olet harrastanut。本课程不系统讲过去时与完成体，但这类形式在口语任务里反复出现，所以本讲把它作为「识别级」内容讲清构成，能听懂、能仿说即可。

学完本节你应当能够：

  • 说出二十个以上爱好名词，并区分「运动项目」与「动作名词」两类表达
  • 用 Harrastan + 部分格 说出三个自己的爱好，并正确否定 En harrasta …
  • 回答现在、童年、未来三个时间层的爱好问句，并用 olen harrastanut、haluan harrastaa 作答
  • 把动词短语改写成名词短语（katson elokuvaa → elokuvan katsominen）
  • 用礼貌开场完成一次六人访谈，并汇报结果

6.1 爱好词汇：两类名词

材料的爱好表混合了两类词，先分清类别，后面变格才不会乱：

类别例子特点
运动 / 游戏项目jalkapallo（足球）, koripallo（篮球）, jääkiekko（冰球）, golf, tennis, sulkapallo（羽毛球）, keilaus（保龄球）多为具体名词，作宾语时通常用部分格
身体活动pyöräily（骑车）, uinti（游泳）, hiihto（滑雪）, retkeily（徒步）, ulkoilu（户外活动）, kuntosali（健身房）多为 -u/-y 或 -ilu 结尾的动作名词
艺术 / 手工tanssi（舞蹈）, teatteri（戏剧）, maalaus（绘画）, piirtäminen（画画）, käsityö（手工）, kokkaus（烹饪）动作名词居多，也可指活动本身
音乐musiikki（音乐）, musiikin kuuntelu（听音乐）, pianon soitto（弹钢琴）, kitaran soitto（弹吉他）「听 / 弹」用属格 + 动作名词
观看类elokuvan katsominen（看电影）属格 + -minen 结构

注意最后两类不是单个名词，而是「属格 + 动作名词」的短语：musiikin kuuntelu 直译是「音乐的听」，pianon soitto 是「钢琴的弹」，elokuvan katsominen 是「电影的看」。芬兰语用属格标出动作的对象。第 9 讲会讲属格，这里先当成固定短语记住。

6.2 harrastaa + 部分格

材料的口语卡明确标注了答句格式：Harrastan … + -a/-ä，例 Harrastan tanssia.（我爱好跳舞）。这个 +a/-ä 就是部分格。原因与第 1 讲的「说语言」相同：爱好是一种持续、非整体的活动，宾语取部分格。

爱好harrastaa 的宾语形式说明
tanssitanssiai 结尾 + a
jalkapallojalkapalloao 结尾 + a
uintiuintiai 结尾 + a
hiihtohiihtoao 结尾 + a
judojudoao 结尾 + a
kuntosalikuntosaliai 结尾 + a
valokuvausvalokuvaustaus 结尾 + ta
käsityökäsityötäö 结尾 + tä
musiikkimusiikkiai 结尾 + a
lukeminenlukemista-nen 结尾 → -sta

否定式：En harrasta jalkapalloa.（我不踢足球。）否定句里宾语本来就是部分格，所以词形不变，只是动词变成 en harrasta。

与 harrastaa 常混用的还有 pelata（玩球类、游戏）与 tehdä（做）。区别在于：harrastaa 强调「长期爱好」，pelata 强调具体玩的行为：Harrastan jalkapalloa（我爱好足球）／Pelaan jalkapalloa joka viikko（我每周踢球）。两者后面都接部分格。

6.3 三个时间层的爱好问句

材料的三问是本讲最值得背下来的句型组，因为它把现在、过去、将来放在一起：

问句含义答句模板
Mitä harrastat (nyt)?你现在爱好什么？Harrastan … + 部分格
Mitä olet harrastanut lapsena?你小时候练过什么？Olen harrastanut … + 部分格
Mitä haluat harrastaa tulevaisuudessa?你将来想爱好什么？Haluan harrastaa … + 部分格

lapsena 是 lapsi 的样格（-na），意为「作为孩子时、小时候」；tulevaisuudessa 是「在未来」，第 4 讲已出现。这两个时间词分别把句子推向过去与将来。

第二问的答句用了 olen harrastanut。这是完成体（perfect）形式：olla 的现在时 + 主动词的过去分词 -nut/-nyt。构成为：动词词干 + -nut（后元音）或 -nyt（前元音）。harrastaa → harrastanut、tanssia → tanssinut、pelata → pelannut。

识别级要求本课程不要求你主动变出所有完成体形式，但必须能听懂 Olen harrastanut …、Oletko harrastanut …?、Olen asunut Suomessa kaksi vuotta 这类句子，并仿说出 2–3 个常见动词的完成体（harrastanut、ollut、asunut、opiskellut）。

第三问的 haluat harrastaa 是「情态动词 + 不定式」结构：haluan（我想要）后面直接接动词原形，不接 -maan 形式。Haluan harrastaa judoa.（我想练柔道。）注意与第 4 讲的 tulen harrastamaan 区分：tulla 后用 -maan，haluta 后用原形。

6.4 把动作变成名词：三种手段

材料里的爱好词大量是「动作名词」，掌握三种构词手段就能自己造：

手段例子构成
-minen（最通用）elokuvan katsominen, piirtäminen, lukeminen, pelaaminen, uiminen动词词干 + -minen；作主语或宾语时 -nen 变 -se-（katsomista）
-u / -y（动作过程）uinti, hiihto, pyöräily, retkeily, ulkoilu, tanssi, maalaus, kokkaus常由动词词干加 -u/-y 或 -ilu/-aus 构成
-us / -os（结果名词）valokuvaus, ostos, kokemus词干 + -us/-os
复合短语（属格 + 名词）musiikin kuuntelu, pianon soitto, elokuvan katsominen对象用属格，动作名词在后

最常见的还是 -minen。它的变格很规律：作主语时 Elokuvan katsominen on hauskaa（看电影很有趣）；作宾语时 -nen 变 -se- 再加部分格 Harrastan elokuvan katsomista（我爱好看电影）。

不要混用Harrastan elokuvan katsominen 是错的（宾语位置需要部分格 katsomista）；Harrastan katsoa elokuvaa 语法上能懂但不地道，规范说法是 Harrastan elokuvan katsomista 或直接用动词 Katson elokuvia。

6.5 频率与程度副词

谈爱好离不开频率，材料在阅读段落与练习里给了这些词：

  • usein 经常；joskus 有时；aina 总是；ei koskaan 从不。
  • joka päivä 每天；joka viikko 每周；kerran viikossa 一周一次；kaksi kertaa viikossa 一周两次。
  • paljon 很多；vähän 一点；tarpeeksi 足够。

注意 kerran viikossa 里 viikossa 是内格，表示「在一周之内（发生一次）」；kertaa 是 kerta 的部分格，因为前面有数词（第 10 讲规则）。

6.6 访谈任务的完整脚本

材料的访谈作业要求采访六个人，并给了一段开场白：Anteeksi, saanko kysyä kolme kysymystä? Tehtävä on minun suomen kurssille.（打扰一下，我可以问三个问题吗？这是我芬兰语课的任务。）这句话本身就是很好的句型素材：

  • Anteeksi —— 打扰一下（也可用于道歉）。
  • Saanko kysyä …? —— 我可以问……吗？（saada 的第一人称 + -ko，礼貌请求）
  • Tehtävä on minun suomen kurssille —— 任务是为我的芬兰语课（kurssille 是 -lle，表示「为……之用」）。

正式提问前先确认对方身份：Kuka sinä olet?（你是谁？）。注意这里用 kuka 而不是 mikä，因为问的是人。若问名字则用 Mikä sinun nimi on?。

汇报结果时把第三人称用起来：Pernilla harrastaa ratsastusta.（佩尼拉爱好骑马。）Tomas ja Sadiq harrastavat jalkapalloa.（两人用 harrastavat，复数主语配第三人称复数）。

6.7 常见错误与自检

高频错误 1Harrastan tanssi. 缺部分格。应为 Harrastan tanssia.
高频错误 2Minun harrastus on jalkapallo. 这句话语法上成立（「我的爱好是足球」），但课堂上更常用动词句。若用名词句，主语与表语都要主格，不要给表语加部分格。
高频错误 3Haluan harrastaa judoa 写对，但 Haluan harrastamaan judoa 是错的（haluta 后接原形，不接 -maan）。
口语加分访谈结束说一句 Kiitos paljon vastauksista!（非常感谢你的回答），其中 vastauksista 是 vastaus 的复数出格，属固定搭配，整句背下来即可。
用法对照

harrastaa 后接部分格，因为爱好是持续、非整体的活动：Harrastan tanssia / jalkapalloa / uintia，否定 En harrasta jalkapalloa 里宾语本就是部分格，词形不变。与 pelata 的分工是「长期爱好」对「具体在玩」：Harrastan jalkapalloa 对 Pelaan jalkapalloa kaksi kertaa viikossa，两者都带部分格。动作名词化有两条路：-minen 最通用，作宾语时 -nen 变 -se- 再加部分格（elokuvan katsominen → Harrastan elokuvan katsomista），对象用属格；-u/-y 或 -us 构成 uinti, hiihto, valokuvaus。三个时间层靠词形区分：Harrastan uintia nyt / Olen harrastanut voimistelua lapsena（lapsena 是样格「小时候」）/ Haluan harrastaa hiihtoa tulevaisuudessa。注意 haluta 后接原形而非 -maan，Haluan harrastamaan 错；完成体 olen harrastanut 只需识别与仿说。频率 kerran viikossa 里 viikossa 是内格、kertaa 是部分格。

例 1　把「我小时候练过体操，现在爱好游泳，将来想学滑雪」说成三句芬兰语。

解：Olen harrastanut voimistelua lapsena. / Harrastan uintia nyt. / Haluan harrastaa hiihtoa tulevaisuudessa.

核对：三句宾语都是部分格（voimistelua、uintia、hiihtoa）；三句动词分别是完成体、现在时、情态 + 原形。

例 2　把 Katson elokuvaa illalla. 改写成以动名词作宾语的句子。

解：对象 elokuva 变属格 elokuvan，动词 katsoa 变动名词 katsominen，作宾语时再变部分格 katsomista。整句：Harrastan elokuvan katsomista illalla.

更自然：Minun harrastus on elokuvien katsominen.（我的爱好是看电影，复数对象用 elokuvien）。两种都可，关键是属格 + -minen 的结构不能丢。

例 3　回答 Mitä sinä harrastat?，要求用 pelata 与 harrastaa 各一句，并说明差别。

解：Harrastan jalkapalloa ja sählyä.（我爱好足球和软式曲棍球）/ Pelaan jalkapalloa kaksi kertaa viikossa.（我一周踢两次足球。）

差别：harrastaa 说「这是长期爱好」，pelata 说「具体在玩」，后者常配频率短语。两句的宾语都用部分格。

例 4　改错：Minä harrastan valokuvausta ja minä haluan harrastamaan judoa.

解：第一句正确（valokuvaus → valokuvausta 是 -us 结尾加 -ta）。第二句错在 harrastamaan，haluan 后要接原形：Minä haluan harrastaa judoa.

规律：haluta、osata、voida 后接原形；tulla、mennä、lähteä 后接 -maan。这是两组情态 / 移动动词的分工。

  1. 写出十个爱好名词的芬兰语，并给每个加上 harrastaa 所需的部分格形式。
  2. 用现在、童年、将来三种时态各写一句关于自己的爱好。
  3. 把下列句子改写成「属格 + 动名词」结构：Kuuntelen musiikkia. / Soitan pianoa. / Piirrän kuvia.
  4. 翻译：「我每周游两次泳，但我不喜欢跑步。」
  5. 写一段 5 句的访谈汇报：三个人各自爱好什么、频率如何、其中一人小时候练过什么。
答案与思路

1. 示例：jalkapallo → jalkapalloa；uinti → uintia；hiihto → hiihtoa；tanssi → tanssia；kuntosali → kuntosalia；valokuvaus → valokuvausta；käsityö → käsityötä；musiikki → musiikkia；teatteri → teatteria；keilaus → keilausta。

2. 示例：Harrastan uintia nyt. / Olen harrastanut tanssia lapsena. / Haluan harrastaa kiipeilyä tulevaisuudessa.

3. musiikin kuuntelu / pianon soitto / kuvien piirtäminen（复数对象用 kuvien）。若作宾语则动名词再变部分格：Harrastan musiikin kuuntelua.

4. Uin kaksi kertaa viikossa, mutta en pidä juoksemisesta. 「不喜欢跑步」用 pitää + -sta（第 11 讲），juokseminen 的 -sta 形式是 juoksemisesta。

5. 示例：Pernilla harrastaa ratsastusta kolme kertaa viikossa. Tomas pelaa jalkapalloa joka viikko. Sadiq on harrastanut judoa lapsena. He harrastavat myös ulkoilua. 注意第三人称单数与复数动词的一致性。

必考harrastaa + 部分格、三种时间层的问句与答句、属格 + -minen 的名词化结构。口语考试与写作都可能直接调用这些句型。
易错 1Harrastan tanssi 缺部分格，是最常见的一处丢分。
易错 2haluan harrastamaan 混用 -maan 与不定式。
易错 3elokuvan katsominen 里忘掉属格：elokuva katsominen 不成立。
进阶能主动用完成体说出 Olen harrastanut … lapsena，并解释 -nut/-nyt 与元音和谐的关系。

谈爱好清单

三时问答

  1. 现在：Mitä harrastat? → Harrastan + 部分格
  2. 童年：Mitä olet harrastanut lapsena? → Olen harrastanut + 部分格
  3. 将来：Mitä haluat harrastaa tulevaisuudessa? → Haluan harrastaa + 部分格

名词化三步

  1. 找出动作对象，变属格（elokuva → elokuvan）
  2. 动词变 -minen / -u / -us 形式（katsoa → katsominen）
  3. 整体作宾语时，-nen 变 -se- 再加部分格（katsomista）
