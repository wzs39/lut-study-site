本节定位

第三讲把第 2 讲的时间格补完整：季节用 -lla、月份用 -ssa，这一讲再加两类——星期用 -na、钟点用 -lta/-ltä。四类合起来，才算把 Milloin? 这个问句答全。

同时它引入本课第一个「读法规则」：芬兰语有两套报时系统（传统与数字），传统系统的 puoli（半点）逻辑与汉语、英语都不同，是最容易在听力题里失分的地方，本讲会专门拆开讲。

学完本节你应当能够：

  • 用三种问法问时间，并按传统与数字两种方式读出任意时刻
  • 解释 puoli yksi 为什么是 12:30，不把它读成 1:30
  • 把星期写成 -na 形式、把钟点写成 -lta 形式，并用它们回答 Milloin?
  • 在时间句里加时段限定（aamulla、illalla、yöllä）区分同名的十二小时制时刻
  • 说出日期与星期的书写规范，包括芬兰语不用大写这一点

3.1 三种问时间的说法

问「现在几点」有三种说法，语气与场景不同：Mitä kello on?（最常用）、Paljonko kello on?（口语，偏「多少」）、Kuinka paljon kello on?（更完整、略正式）。三者的答句结构相同，都以 Kello on … 或口语的 Se on … 开头。

注意 kello 有两个意思：一是「钟、表」（名词），二是报时句里的固定成分（Kello on viisi = 五点了）。作为时间单位「小时」时它是 tunti：kaksi tuntia = 两小时。报点用 kello，计时长用 tunti。

3.2 数字时间（digitaalinen aika）

数字时间按「小时 + 分钟」直接读，分钟读成两位数：12.34 读作 Kello on kaksitoista kolmekymmentäneljä；整点读作 Kello on kolmetoista (nolla-nolla)（13:00）。这种读法在火车站、机场、电视节目表里最常见。

数字写法数字时间读法说明
13:00Kello on kolmetoista (nolla-nolla).整点直接读小时，可补 nolla-nolla
21:17Kello on kaksikymmentäyksi seitsemäntoista.小时 + 分钟两个数
5:25Kello on viisi kaksikymmentäviisi.小时不加「零」
17:30Kello on seitsemäntoista kolmenkymmentä.分钟 30 读 kolmenkymmentä
9:45Kello on yhdeksän neljäkymmentäviisi.分钟 45 读 neljäkymmentäviisi
11:55Kello on yksitoista viisikymmentäviisi.分钟 55 读 viisikymmentäviisi
小时数的读法13–19 按 kolmetoista … yhdeksäntoista；20 以上按 kaksikymmentäyksi 这类复合数连写。注意 24 小时制里 21 读 kaksikymmentäyksi，不是 yhdeksäntoista 加别的。

3.3 传统时间（perinteinen aika）：yli 与 vailla

传统系统以「下一个整点」或「上一个整点」为参照，用两个介词性词：yli（过）与 vailla / vaille（差）。规则如下：

规则一（过半点之前）：分钟 + yli + 当前小时。12:10 = kymmenen yli kaksitoista；12:15 = viisitoista yli kaksitoista，也可说 vartin yli kaksitoista。

规则二（过半点之后）：剩余分钟 + vailla / vaille + 下一个小时。12:40 = kaksikymmentä vailla yksi（差二十分一点）；12:45 = varttia vailla yksi 或 viisitoista vailla yksi。

规则三（半点）：puoli + 下一个小时。12:30 = puoli yksi。这是全课最反直觉的一条：芬兰语的 puoli yksi 直译是「一半的一点」，意思是「朝着一点走了一半」，即 12:30，不是 1:30。

规则四（整点）：Kello on (tasan) yksi，tasan 表示「整」。

时刻传统读法关键点
12:00Kello on (tasan) kaksitoista.整点
12:10kymmenen yli kaksitoistayli + 当前小时
12:15viisitoista yli kaksitoista / vartin yli kaksitoistavartti = 一刻钟

12:40kaksikymmentä vailla yksivailla + 下一个小时
12:45varttia vailla yksi / viisitoista vailla yksi两种说法都常见
11:55viisi vailla kaksitoista差五分十二点
5:25kaksikymmentäviisi yli viisiyli + 当前小时

21:17seitsemäntoista yli yhdeksänyli + 当前小时
puoli 的逻辑把 puoli yksi 理解成「十二点半」。凡是听到 puoli，先取后面那个数，减一，再想「那个小时的半点」。同理 puoli kuusi = 5:30，puoli kymmenen = 9:30。

vailla 与 vaille 是同一词的两种形态，材料注明 vailla = vaille，两者都可使用；口语里 vaille 更常见。vartti（一刻钟）的部分格是 varttia，属格是 vartin，所以「一刻过」有两种说法：vartin yli 与 varttia yli。

3.4 加时段限定：区分同名时刻

十二小时制里 12:30 与 00:30 都读 puoli yksi，靠时段词区分：Kello on puoli yksi päivällä（中午十二点半）／Kello on puoli yksi yöllä（夜里十二点半）。常用时段词：

时段词含义例句
aamulla早上Kello on viisi aamulla.
päivällä白天 / 中午Kello on puoli yksi päivällä.
aamupäivällä上午Kello on kymmenen aamupäivällä.
iltapäivällä下午Kello on viisi iltapäivällä.
illalla晚上Kello on yhdeksän illalla.
yöllä夜里Kello on puoli yksi yöllä.

这四个词全部是 -lla 形式，与第 2 讲的季节同理：把时段看作「时间表面」。

3.5 时间单位与换算

  • sekunti 秒；minuutti 分；tunti 小时；vuorokausi / päivä 一天；viikko 一周。
  • 60 sekuntia = minuutti；60 minuuttia = tunti；24 tuntia = vuorokausi；7 päivää = viikko。
  • kuukausi 月；vuosi 年；vuosikymmen 十年。

注意数量表达：kaksi tuntia、kolme päivää、viisi minuuttia —— 2 以上的数词后面接部分格单数，这与第 1 讲的 kaksikymmentä vuotta 一致。

3.6 Milloin 的四类时间格

把这一讲与第 2 讲合起来看，Milloin? 的答句按名词类别分成四种后缀，这是本课程时间表达的总纲：

钟点（几点）-lta/-ltäyhdeltä, kahdelta, kolmelta, kuudelta, kymmeneltä「从某个钟点起」→ 从格
星期（周几）-na/-nämaanantaina, tiistaina, keskiviikkona, torstaina, perjantaina, lauantaina, sunnuntaina「作为那一天」→ 样格
月份（几月）-ssa/-ssätammikuussa … joulukuussa「在月份内部」→ 内格

3.7 星期的写法与缩写

七个星期词与缩写：maanantai(MA)、tiistai(TI)、keskiviikko(KE)、torstai(TO)、perjantai(PE)、lauantai(LA)、sunnuntai(SU)。全部小写；缩写只在表格、课表里用，句子里要写全。

问「今天星期几」用 Mikä päivä nyt on?，答 Nyt on tiistai（主格，因为是在「指认」哪一天）。问「星期几做某事」用 Milloin …? 或 Minä päivänä …?，答句用 -na：Suomen tunti on tiistaina。

注意区分 päivä 的两个用法：Mikä päivä on?（今天星期几）与 Minä päivänä?（在哪一天）。前者问「哪一天（星期）」，后者问「具体哪一天」。

3.8 日期与语序

日期写作「日. 月份的部分格」：14. helmikuuta（2 月 14 日），读作 neljästoista helmikuuta。月份在此用部分格，因为日期是「月的一部分」。年份用 vuonna 1999。完整日期：3. marraskuuta 1999。

句子里时间词的位置比较自由：可以句首（Maanantaina minä käyn salilla）也可以句尾（Minä käyn salilla maanantaina）。句首位置通常用来强调时间，书面语更常见。

高频错误 1puoli kolmetoista 是错的。传统系统只用 1–12 的小时数，13 以上只出现在数字时间读法里。
高频错误 2kello viideltä 与 Kello on viisi 混淆。前者是「五点时（做事）」，后者是「现在五点」。前者必带 -lta，后者不带。
听力策略听到 yli 就往回取当前小时，听到 vailla / vaille 或 puoli 就往前取下一个小时。先定方向，再算分钟，最后核对时段词。
发音提示

数字时间按「小时 + 分钟」两数直读：17.30 是 seitsemäntoista kolmenkymmentä。传统时间用三个钥匙：yli（过）取当前小时，vailla/vaille（差）取下一个小时，puoli 也取下一个小时但在其前减一——puoli yksi 是 12:30 而非 1:30，puoli kuusi 是 5:30，听到 puoli 先减一最稳。vartti（一刻）两形：vartin yli 与 varttia vailla。传统式只用 1–12 的小时数，puoli kolmetoista 错。报点用 kello（Kello on viisi），计时长用 tunti（kaksi tuntia），两者不可换。Milloin 四类格收拢成表：钟点 -lta（yhdeltä, kahdelta）、星期 -na（tiistaina）、月份 -ssa、季节与时段 -lla（aamulla, illalla）。日期写 14. helmikuuta，月份用部分格，因为是一月中的一部分。

Mihin aikaan?几点？Asks for a clock time: Mihin aikaan syöt?
例 1　把 17:30 用传统与数字两种方式读出来。

解：传统：puoli kuusi（朝着六点走了一半 → 5:30），若要限定可说 puoli kuusi iltapäivällä。数字：Kello on seitsemäntoista kolmenkymmentä。

易错点：不要读成 puoli seitsemän（那是 6:30），也不要读 puoli seitsemäntoista。

例 2　把 9:45 读成传统时间，并说明为什么用 vailla 而不是 yli。

解：45 分已经过了半点，按规则要往下一个整点（10 点）数差多少：差 15 分。所以是 varttia vailla kymmenen 或 viisitoista vailla kymmenen。

判断口诀：分钟 ≤ 30 用 yli + 当前小时；分钟 > 30 用 vailla + 下一小时；正好 30 用 puoli + 下一小时。

例 3　回答 Milloin sinä heräät?，设定 6:40 起床。

解：6:40 的分钟大于 30，用 vailla 加下一个小时：差 20 分七点 → Herään kaksikymmentä vailla seitsemän。也可加时段：Herään kaksikymmentä vailla seitsemän aamulla。

语法点：答句的动词用第一人称（herään），时间短语放在句尾，时间词本身不再加 -lta，因为 vailla 结构已经表示「差多少到几点」。

例 4　把「星期二我在校园，从九点到十二点有芬兰语课」译成两句芬兰语。

解：第一句：Tiistaina olen kampuksella.（星期 -na，地点 -lla，kampusi → kampuksella 有 k→ks 的变化）。第二句：Suomen tunti on yhdeksästä kahteentoista.

要点：表示时间段「从几点到几点」用 -sta … -hVn（elative + illative）：yhdeksästä（从九点）、kahteentoista（到十二点）。这与单点时刻的 -lta 不同，材料正文只给了单点，属衔接性拓展。

  1. 用传统时间读出：7:15、11:40、14:30、18:55、22:05。
  2. 用数字时间读出：8:30、13:00、16:45、19:10。
  3. 把七个星期写成 -na 形式，并用其中三个各造一句 Milloin …? 的答句。
  4. 翻译：「我每天早上七点起床，晚上十一点睡觉。」
  5. 改错：Kello on puoli kolmetoista. / Kello on viisi yli kaksitoista（想表达 11:55）/ Menen nukkumaan kello yksitoista.
答案与思路

1. 7:15 vartin yli seitsemän；11:40 kaksikymmentä vailla kaksitoista；14:30 puoli kolme（下午两点半）；18:55 viisi vailla seitsemän；22:05 viisi yli kymmenen（晚上）。

2. 8:30 kahdeksan kolmenkymmentä；13:00 kolmetoista (nolla-nolla)；16:45 kuusitoista neljäkymmentäviisi；19:10 yhdeksäntoista kymmenen。

3. maanantaina, tiistaina, keskiviikkona, torstaina, perjantaina, lauantaina, sunnuntaina。答句示例：Minä urheilen maanantaina ja torstaina. / Suomen tunti on keskiviikkona. / Käyn salilla lauantaina.

4. Herään joka päivä seitsemältä aamulla ja menen nukkumaan yhdeltätoista illalla. 注意两个钟点都用 -lta，「每天」用 joka päivä（joka 后不加格）。

5. 三处：puoli kolmetoista → puoli yksi（12:30）或按需 puoli kaksi；11:55 应说 viisi vailla kaksitoista；kello yksitoista → yhdeltätoista。

必考传统时间的 yli / vailla / puoli 三件套、星期 -na 与钟点 -lta 的形式、Milloin? 四类时间格的分工。听力题几乎必出报时。
易错 1puoli 指向下一个小时：puoli yksi = 12:30，写反是最常见的失分点。
易错 2小时数超过 12 时仍用传统系统：puoli neljätoista 不成立。
易错 3星期写成 -ssa 或 -lla：maanantaissa、maanantailla 都错，应为 maanantaina。
进阶能用 -sta … -hVn 表达时间段（yhdeksästä kahteentoista），并解释它与单点 -lta 的语义差别。

报时与时间格清单

读任意时刻四步

  1. 先判分钟段：≤ 30 用 yli，= 30 用 puoli，> 30 用 vailla
  2. yli：分钟 + yli + 当前小时
  3. puoli：puoli + 下一小时
  4. vailla：差值 + vailla + 下一小时
  5. 需要时补时段词 aamulla / päivällä / illalla / yöllä

时间格四选一

  1. 钟点 → -lta：yhdeltä、kahdelta
  2. 星期 → -na：tiistaina、viikonloppuna
  3. 月份 → -ssa：huhtikuussa
  4. 季节与时段 → -lla：kesällä、illalla
