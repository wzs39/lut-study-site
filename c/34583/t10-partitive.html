本节定位

第十讲是全课程语法上最重要的一讲。部分格（partitiivi）在前面九讲里已经反复出现：vuotta（年龄）、vettä（喝水）、tanssia（爱好）、porkkanoita（买胡萝卜）、ei ole kissaa（没有猫）。这一讲把这些散点收成一套完整规则。

它也是芬兰语区别于其他欧洲语言最明显的地方：宾语不只有一种形式。同一个动作，做完与没做完，宾语要用不同的格（katson elokuvan / katson elokuvaa）。这一点直接决定句子的意思，不只是「语法细节」。

学完本节你应当能够：

  • 按五条主规则为任意单数名词造出部分格，并处理 -nen、vesi、pieni 等特殊词
  • 按三条规律为常见名词造出部分格复数
  • 说出部分格五大用法：数词后、否定句、部分格动词后、monta 后、不可数名词
  • 区分「部分格宾语」与「总格宾语」在意义上的差别，并按语境选择
  • 把一个打乱的词串组成正确的芬兰语部分格句（考试固定题型）

10.1 部分格到底表示什么

材料用一句话概括：Partitive case has a meaning 「part of」 something，例 （osa） leipää = 一块 / 一些面包。所以部分格的核心语义是「一部分、不定量、未完成」。

由此推出两条使用逻辑：

  1. 量上的一部分：一块面包、一些水、两个鸡蛋 —— 都不是「全部」。
  2. 动作上未完成：正在看、看着、看了一会儿 —— 动作没有走到终点。

这两条逻辑覆盖了本讲所有用法。凡是句子里出现「不确定多少」或「没做完」，宾语几乎都用部分格。

10.2 部分格单数：五条主规则

材料把构成规则按词尾分成五组，逐组给了大量填空例词。下面把规则与例词一并列出（例词即练习题的标准答案）：

规则条件例词 → 部分格说明
规则一词尾是元音（e 除外）kynä → kynää；auto → autoa；läppäri → läppäriä；kirja → kirjaa；kinkku → kinkkua；ruoka → ruokaa；maito → maitoa；leipä → leipää；pizza → pizzaa；jäätelö → jäätelöä；raha → rahaa直接加 -a / -ä；注意元音和谐
规则二词尾是 evene → venettä；tietokone → tietokonetta；huone → huonetta；vaate → vaatetta；perhe → perhettä加 -tta / -ttä
规则三词尾是 ibussi → bussia；pankki → pankkia；lasi → lasia；äiti → äitiä；lehti → lehteä；lahti → lahtea；poski → poskea；järvi → järveä一般加 -a/-ä；部分词 i → e 再加 -a/-ä
规则四词尾是辅音avain → avainta；puhelin → puhelinta；tulostin → tulostinta；lounas → lounasta；sormus → sormusta；pakastin → pakastinta；selain → selainta加 -ta / -tä
规则五短词（单音节）maa → maata；tee → teetä；yö → yötä；työ → työtä加 -ta / -tä，避免出现三个相同元音

规则三的 i → e 需要单独注意：lehti → lehteä、järvi → järveä、lahti → lahtea、poski → poskea。判据不完全可推，但有一条经验：i 前面的音节含 a、e、ä 等前元音时更容易变成 e；bussi、pankki、lasi 这类则保留 i。

规则五的存在是为了避免三个相同元音连排：maa + a 若写成 maaa 不可读，所以改用 -ta 得 maata。同理 tee → teetä、yö → yötä。

10.3 特殊词尾与例外

材料专门列了「Erikoiset tapaukset」（特殊情况），这些必须整块记：

类型例词 → 部分格说明
-nen 结尾punainen → punaista；nainen → naista；sininen → sinistä；virolainen → virolaista-nen 变 -sta / -stä
-si 结尾的旧词vesi → vettä；vuosi → vuotta；kuusi（六）→ kuutta；kuukausi → kuukautta去掉 -si，按词干加 -ta/-ttä
i 脱落pieni → pientä；suuri → suurta；kuori → kuortai 去掉后加 -ta/-tä
人名David → Davidia；Hamad → Hamadia；Susan → Susania；Alex → Alexia；Mirjam → Mirjamia；Martin → Martinia；Marjut → Marjutia辅音结尾的人名先加 -i- 再加 -a/-ä

-nen 结尾的规律与第 9 讲属格一致：-nen 的词在变格时整体换成 -se- 词干（nainen → naise-），部分格就是 naista，属格是 naisen。记住「-nen → -se-」这一个动作，两类格都能推。

人名规则值得单拎出来：David 结尾是辅音 d，直接加 -a 会得到不可读的 Davida？实际上芬兰语的处理是先加 i：Davidia、Hamadia、Susania。这与第 9 讲属格「辅音结尾加 i 再加 n」是同一个思路。

10.4 部分格复数：三条主要规律

材料给出的是三条最常用规律，并强调「由主格结尾决定」：

主格词尾部分格复数词尾例词
o, ö, u, y-ja / -jäkoulu → kouluja；työ → töitä（例外，见下）；halo → haloja
i-eja / -ejätuoli → tuoleja；bussi → busseja；pankki → pankkeja
a, i, in-ia / -iäkoira → koiria；kirja → kirjoja（a → o + ja）；kissa → kissoja
e-ita / -itähuone → huoneita；vaate → vaatteita
-nen-sia / -siänainen → naisia；punainen → punaisia

材料原文只给了前三行（o/ö/u/y → -ja；i → -eja；a/i/in → -ia），后两行是同类词的类推结果，用来补齐实际会遇到的 huoneita、naisia。

注意 a → o + ja 这一小步：kirja → kirjoja、kissa → kissoja、koira → koiria（这里 a 直接变 i + a）。同样是 a 结尾，词干不同结果不同，所以复数部分格也要按词记，遇到新词先查再写。

10.5 部分格的五大用法

材料列出的用法条目是这一讲最该背下来的清单，每条都配了例句：

用法例句说明
① 数词 + 具体名词kaksi koiraa；kolme munaa；kaksi porkkanaa2 以上接部分格单数，不是复数
② 否定动词 + 具体名词Minulla ei ole koiraa.；Tarja ei osta tietokonetta.否定句宾语一律部分格
③ 部分格动词Rakastan sinua.；Katson koiraa.；Etsin opettajaa.这类动词的宾语习惯用部分格
④ monta（许多）Monta koiraa.monta 后面接部分格单数
⑤ 不可数名词Juon vettä.；Haluan teetä.液体、粉末、物质用部分格

第 ③ 条需要一份动词清单，材料在复习题里给了足够的样本：auttaa（帮助）、rakastaa（爱）、etsiä（找）、katsoa（看）、odottaa（等）、kuunnella（听）、lukea（读）、pelata（玩）、ostaa（买，否定时）、syödä（吃，部分时）。这些动词的共同点是：动作可以「没完」，或对象本身是「一部分」。

第 ② 条的否定规则要连带注意主语：Minulla ei ole koiraa 里 minulla 不变，只有宾语变。而 Tarja ei osta tietokonetta 里 tietokone → tietokonetta，是 e 结尾加 -tta 的规则二。

10.6 部分格宾语与总格宾语的对立

这是芬兰语语法的核心机制，也是材料没有明说但反复示范的差别。看两组对照：

句子含义宾语的格
Katson elokuvan.我要看完这部电影（整部）。总格 -n
Katson elokuvaa.我正在看电影（没看完）。部分格 -a
Ostan leivän.我买（一整个）面包。总格 -n
Ostan leipää.我买些面包。部分格 -a
Syön omenan.我把一个苹果吃掉。总格 -n
Syön omenaa.我在吃苹果（吃着一部分）。部分格 -a
Juon maidon.我把（那杯）牛奶喝完。总格 -n
Juon maitoa.我喝（一些）牛奶。部分格 -a

判断口诀：结果完整 → 总格；过程未完 / 数量不定 → 部分格。此外三种情况永远用部分格：否定句、数词 2 以上、不可数名词。这三条是硬规则，不需要判断语感。

最容易被扣分的地方把「我喝牛奶」写成 Juon maidon。牛奶不可数，必须是 Juon maitoa。同理 Syön leipää（吃面包）比 Syön leivän（吃掉一整个）更常用于日常描述。

10.7 造句练习：语序不变、动词变位、宾语部分格

材料的复习题给了 11 组词，要求「用语序不变、动词变位、宾语用部分格」造出句子。这正好是考试题型，下面给出全部标准答案并标注操作步骤：

给定词标准答案关键操作
Minä – auttaa – naapuriMinä autan naapuria.auttaa 第一类，naapuri → naapuria
Sinä – syödä – kana – ja – riisiSinä syöt kanaa ja riisiä.syödä 第二类；两个宾语都部分格
Juoda – sinä – olut?Juotko sinä olutta?疑问句动词加 -ko，olut → olutta
He – rakastaa – jäätelöHe rakastavat jäätelöä.rakastaa 第一类，he → -vat
Sanna – etsiä – avainSanna etsii avainta.etsiä 第一类，avain → avainta
Tarja – ei ostaa – tietokoneTarja ei osta tietokonetta.否定式 + e 结尾 -tta
Te – katsoa – puhelinTe katsotte puhelinta.katsoa 第一类，puhelin → puhelinta
Me – odottaa – bussiMe odotamme bussia.odottaa 第一类，bussi → bussia
Minä – ei kuunnella – musiikkiMinä en kuuntele musiikkia.kuunnella 第三类，musiikki → musiikkia
Te – lukea – lehtiTe luette lehteä.lukea 第一类，lehti → lehteä（i → e）
He – ei pelata – jalkapalloHe eivät pelaa jalkapalloa.pelata 第四类，否定 eivät pelaa

最后一行值得单独说明：pelata 属第四类，词干 pelaa-，否定式是 eivät pelaa（不是 pelata）。jalkapallo → jalkapalloa 是 o 结尾加 -a。

  1. 读词串，找出主语 → 定动词 → 判动词类型 → 变位
  2. 找出宾语，按规则造部分格（元音 / e / i / 辅音 / 短词）
  3. 检查是否否定句或数词，若是则确认部分格
  4. 检查语序与原文一致，疑问句记得给动词加 -ko/-kö

10.8 常见错误汇总

高频错误 1数词后接主格：kolme muna 错，应为 kolme munaa。
高频错误 2e 结尾忘加 -tta：huonea 错，应为 huonetta。
高频错误 3-nen 结尾按普通词处理：naista 对，naisena 式的类推错；punainen → punaista。
高频错误 4不可数名词用总格：Juon maidon、Ostan leivän（若只想说「买些面包」）。
终极自检写完宾语问一句：这个动作「做完了吗」「数量确定吗」。两个都是「是」才用总格，否则用部分格。
用法对照

部分格核心语义是「一部分、不定量、未完成」，由此推出五大硬用法：数词 2 以上（kaksi koiraa，接部分格单数）、否定句（Minulla ei ole koiraa）、部分格动词（Rakastan sinua, Etsin avainta）、monta 后（monta koiraa）、不可数名词（Juon vettä）。构成五规则：元音结尾加 -a/-ä（kirjaa, ruokaa），e 结尾加 -tta/-ttä（huonetta, venettä），i 结尾多加 -a 但部分变 e（lehti→lehteä），辅音结尾加 -ta/-tä（avainta, lounasta），短词加 -ta 免三元音连排（maa→maata, yö→yötä）。特殊词整块记：-nen→-sta（naista, punaista）、vesi→vettä, vuosi→vuotta、pieni→pientä、辅音结尾人名先加 i（Davidia）。最关键的对立是宾语：Katson elokuvan（看完这部）对 Katson elokuvaa（正在看）；口诀「结果完整用总格，过程未完或数量不定用部分格」。

宾语是部分格还是属格：一条判据

宾语格选择看动作是否及于「整体」：整体完成 → 属格（Syön omenan 我把苹果吃完）；部分/进行/未完成 → 部分格（Syön omenaa 我正在吃苹果/吃一部分）。否定句宾语永远部分格（En syö omenaa）。数量词后的宾语也走部分格（ostan kaksi kirjaa）。考试题往往把「进行中」和「将完成」混排，先问完成度再选格。

例 1　给 huone、avain、vesi、punainen、pieni 造部分格，并说明各自适用哪条规则。

解：huone → huonetta（规则二：e 结尾加 -tta）；avain → avainta（规则四：辅音结尾加 -ta）；vesi → vettä（特殊：-si 去掉，双写 t）；punainen → punaista（-nen → -sta）；pieni → pientä（i 脱落加 -tä）。

思路：先看词尾类别，再查特殊表。vesi 与 pieni 不属五条主规则，必须靠记忆表。

例 2　把「我买了三个鸡蛋和两袋牛奶」译成芬兰语。

解：Ostin kolme munaa ja kaksi maitoa. 若用现在时：Ostan kolme munaa ja kaksi maitoa.

要点：数词 3 与 2 后面都接部分格单数（munaa、maitoa）。maito 本身不可数，部分格 maitoa 兼有「一些牛奶」的意思。

例 3　比较 Luen kirjaa 与 Luen kirjan，说明语境差别。

解：Luen kirjaa = 我在读一本书（读着，没读完）；Luen kirjan = 我把这本书读完（读完或承诺读完）。

语法：前者部分格宾语，后者总格宾语。回答「你在做什么」用前者；回答「你今天要完成什么」用后者。

例 4　改错：Minä en osta tietokone. / Syön kaksi omenat. / Juon vesi.

解：三处都要部分格：Minä en osta tietokonetta.（否定）／Syön kaksi omenaa.（数词）／Juon vettä.（不可数）。

共性：三条不同的规则指向同一个结果——部分格。考试里只要看到否定、数词、物质名词，先写部分格再考虑别的。

  1. 为下列词造部分格单数：talo、huone、bussi、avain、vesi、nainen、pieni、David、työ。
  2. 为下列词造部分格复数：koulu、tuoli、koira、kirja、huone、nainen。
  3. 把 11 组词串中的任意 5 组造成完整句子（语序不变）。
  4. 翻译：「我没有车，但我有很多朋友，我每天喝咖啡、读报纸。」
  5. 判断该用部分格还是总格，并说明理由：Katson (elokuva)（正在看）/ Ostan (leipä)（买一整个）/ Juon (maito)（喝一些）。
答案与思路

1. taloa、huonetta、bussia、avainta、vettä、naista、pientä、Davidia、työtä。逐项核对：e → -tta；辅音 → -ta；-si 特殊；-nen → -sta；i 脱落；人名加 i。

2. kouluja、tuoleja、koiria、kirjoja、huoneita、naisia。注意 kirja → kirjoja 是 a → o + ja，koira → koiria 是 a → i + a。

3. 示例：Minä autan naapuria. / Sinä syöt kanaa ja riisiä. / Juotko sinä olutta? / He rakastavat jäätelöä. / Sanna etsii avainta.

4. Minulla ei ole autoa, mutta minulla on monta ystävää. Juon kahvia ja luen lehteä joka päivä. 三个部分格：autoa（否定）、ystävää（monta 后单数）、kahvia 与 lehteä（不可数 / 部分动作）。

5. 正在看 → 部分格 elokuvaa；买一整个 → 总格 leivän；喝一些 → 部分格 maitoa。

必考部分格单数五条规则 + -nen / vesi / pieni 特殊表、部分格复数三条规律、五大用法、部分格与总格的对立。造句与填空都会直接考。
易错 1e 结尾忘加 -tta：huonea、perhea。
易错 2数词后接主格或复数：kaksi koirat。
易错 3把不可数名词写成总格：Juon maidon。
易错 4否定句忘部分格：En osta tietokone。
进阶能解释 -nen 词干 -se- 的机制（nainen → naise- → naista / naisen），并据此推出属格与部分格两种形式。

部分格操作清单

造部分格单数五步

  1. 看词尾：元音（非 e）→ +a/-ä；e → +tta/-ttä；i → +a/-ä（部分 i→e）；辅音 → +ta/-tä；单音节短词 → +ta/-tä
  2. 查特殊表：-nen → -sta；vesi/vuosi/kuusi/kuukausi；pieni/suuri/kuori
  3. 人名辅音结尾先加 -i-（David → Davidia）
  4. 检查元音和谐：a/o/u 用后元音，ä/ö/y 用前元音

判断用不用部分格三问

  1. 是否否定句？是 → 部分格
  2. 是否数词 2 以上或 monta？是 → 部分格单数
  3. 动作是否完成、数量是否确定？否 → 部分格；是 → 总格
