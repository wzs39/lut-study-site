本节定位

第九讲第一次把「格」当成系统讲。前面八讲已经零散用过 -sta、-ssa、-lla、-na、-lta、-hVn，这一讲先用一张总表把它们归位，再把主格与属格讲透——尤其是属格里的辅音交替方向，这是从第 5 讲延续下来的同一套机制。

属格之所以重要，是因为它不只表示「谁的」：Annan mies（安娜的丈夫）、suomen tunti（芬兰语课）、kahvin vieressä（咖啡旁边）、elokuvan katsominen（看电影）都是属格。第 6 讲的名词化结构在这里得到解释。

学完本节你应当能够：

  • 说出芬兰语主要格的数量与分工，并给每个格一个例词
  • 为主格单数造出属格单数，正确处理元音结尾、辅音结尾与辅音交替三种情况
  • 背出六个人称代词的属格形式，并说出对应的口语缩短形式
  • 为主格单数造出属格复数（-en / -den / -ten 三类）
  • 在正式语体里加所有格后缀（kirjani、kirjasi、kirjamme），并知道口语通常不加

9.1 芬兰语的格：为什么必须系统学

材料第一句就给了一个数字：In Finnish language, we have 15 noun cases. 十五个格听起来可怕，但它们的构造高度规则：绝大多数格 = 词干 + 格词尾，而词干本身只有强、弱两种形态。

本课程重点在五个格：主格、属格、部分格（本讲与第 10 讲）、内格 / 出格（第 1、8 讲）、上格 / 向格 / 从格（第 2、3、4 讲）。其余格只作识别，不必主动产出。

学习顺序建议先把「问什么」背熟：missä（在哪）→ -ssa；mistä（从哪）→ -sta；mihin（去哪）→ -hVn；millä（用什么 / 在哪表面）→ -lla；kenen（谁的）→ -n。问题词与词尾一一对应，比背十五个名字有用。

9.2 主格：词典形式与复数 -t

主格单数就是词典里的形式：kissa、opiskelija、kirja。主格复数加 -t：kissat、opiskelijat、kirjat。材料指出主格用来回答大部分基本问题：

问句答句说明
Mikä se on?Se on kirja.问事物用 mikä
Kuka asuu täällä?Täällä asuu opiskelija.问人用 kuka
Mitkä nämä ovat?Nämä ovat kirjat.复数用 mitkä
Ketkä asuvat täällä?Täällä asuvat opiskelijat.复数人称 ketkä

两句答句的语序值得注意：Täällä asuu opiskelija 把地点放句首、动词居中、主语在末——这是芬兰语常见的「存在句」语序，主语是新的信息。若主语是人称代词则语序正常：Hän asuu täällä。

9.3 属格单数的构成

属格词尾是 -n，意为「……的」。构成分三种情况：

情况规则例子
元音结尾直接加 -nkissa → kissan；Ella → Ellan；tyttö → tytön
辅音结尾先加 -i-，再加 -nJasmin → Jasminin；Eliot → Eliotin；Oscar → Oscarin
含 K/P/T（强弱交替）强级词干变弱级，再加 -nkukka → kukan；kuppi → kupin；paita → paidan

材料给的交替例子很典型，可以当作一组必背样本：

主格（强）属格（弱）交替
kukkakukankk → k
kuppikupinpp → p
tyttötytöntt → t
paitapaidant → d
kenkäkengännk → ng
kampakammanmp → mm
räntärännännt → nn
kertakerranrt → rr
iltaillanlt → ll
lakkalakankk → k
hattuhatuntt → t
taukotauonk → ∅
kipukivunp → v

为什么属格一定取弱级？因为属格词尾 -n 是辅音，它把词干最后一个音节「关住」变成闭音节，闭音节要求弱级 —— 这与第 5 讲第一类动词「minä 形式弱化」是同一条机制。属格 = 弱级 + n，这个公式能解释绝大多数名词。

别忘交替最常见的错误是只加 -n 而不弱化：kukkan、kuppin、paytan 类写法都错。看到词里有 k、p、t 就先问「要不要弱化」。

9.4 人称代词的属格

代词属格单独记，因为它们不规则：

主格属格中文
minäminun我的
sinäsinun你的
hänhänen他 / 她的
memeidän我们的
teteidän你们的
heheidän他们的

例句：Minun tietokone on uusi.（我的电脑是新的。）Sinun kirja on painava.（你的书很重。）Meidän luokka on kylmä.（我们的教室很冷。）注意属格修饰语不加格变化，格加在被修饰的名词上：minun kirja 作宾语时是 minun kirjan（若用总格）。

疑问代词也有属格：kuka → kenen（谁的），mikä → minkä。问句 Kenen tämä koira on?（这只狗是谁的？）答 Se on minun koira.／Se on minun.（省略名词时属格单独作表语）。

9.5 口语形式：mun、sun、meiän

材料专门用一页讲口语缩短形式，这在真实对话里极其常见：

书面口语例句
minunmunMun tietokone on uusi.
sinunsunSun kirja on painava.
meidänmeiänMeiän luokka on kylmä.
teidänteiänTeiän auto on hieno.
hänensenSen kirja on tässä.
heidänheiän / niidenNiiden talo on iso.

口语里 hän 常说 se，he 常说 ne，所以 sen、niiden 既是代词主格的口语形式，也是属格。考试书面语要写 hänen、heidän，听力里要能听懂 mun、sun。

9.6 正式语体的所有格后缀

书面语（尤其正式文本）会在名词上再加一个与 owner 一致的后缀，此时代词可以不写：

人称后缀例句
minä-niMinun tietokoneeni on uusi. / Tietokoneeni on uusi.
sinä-siSinun kirjasi on painava. / Kirjasi on painava.
hän-nsa / -nsäHänen kirjansa on uusi.
me-mmeMeidän luokkamme on kylmä.
te-nneTeidän autonne on hieno.
he-nsa / -nsäHeidän talonsa on iso.

材料给的三个例句正是 Minun tietokoneeni on uusi、Sinun kirjasi on painava、Meidän luokkamme on kylmä。注意加了后缀后，minun 仍可保留（强调），也可省略。

口语里几乎不用后缀，所以第 1 讲的口语卡写的是 Minun nimi on … 而不是 Minun nimeni on …。两种都对，语境不同。

9.7 属格复数

复数属格有三种常见词尾，材料给的是 -(j)en，并提到 -den：

类型词尾例子适用
-(j)en-en / -jenkirjojen, koirien, opiskelijoiden（按 i 结尾加 -en）最常见
-den-denperunoiden, omenoiden, tyttöjen 的变体 tyttöden（少用）a/ä 结尾的复数常两可
-ten-tenlasten, vihannesten, miesten部分旧词与 -nen 结尾词

三类之间不是随机：以 -nen 结尾的词多用 -sten（nainen → naisten，vihannes → vihannesten）；以 -i 结尾多用 -jen（kirja → kirjojen，koska 复数词干 kirjo- + en）；其余常可用 -den 或 -jen（perunoiden / perunojen 后者少用）。

用法：kirjojen hinnat（书的价格）、opiskelijoiden mielipiteet（学生的意见）、lasten vaatteet（儿童服装）。复数属格作前置修饰，被修饰名词用主格或按句法变格。

9.8 属格的四种典型用法

  1. 表示拥有：Tämä salkku on Timon.（这个公文包是蒂莫的。）
  2. 作前置修饰（谁的 / 什么的）：Annan mies（安娜的丈夫）、meidän ystävä（我们的朋友）、suomen tunti（芬兰语课）、talon katto（房子的屋顶）。
  3. 作后置词的宾语：kahvin vieressä（咖啡旁边）、pöydän alla（桌子下面）、sinun kanssa（和你一起）。
  4. 作动作名词的对象：elokuvan katsominen（看电影）、musiikin kuuntelu（听音乐）—— 第 6 讲的结构在这里得到解释。

注意属格修饰语本身不变格，变化落在中心词上：Annan miehen（安娜的丈夫，作宾语）、Annan miehelle（给安娜的丈夫）。这条「前修饰语不变、中心词变格」的规则在第 4 讲的 ensi viikolla 已经出现过。

9.9 常见错误

高频错误 1忘掉辅音交替：kukkan、kuppin。属格必须弱化。
高频错误 2辅音结尾的名字不加 -i-：Oscarn 错，应为 Oscarin；Jasminn 错，应为 Jasminin。
高频错误 3把口语形式写进正式作文：mun kirja 在考试作文里应写 minun kirjani 或 minun kirja。
自检口诀写属格前问三句：① 词尾是元音还是辅音？② 词里有没有 k/p/t？③ 有没有 -nen 结尾（→ -sen）？三问过完再落笔。
常见误解

15 个格里本课程重点五个：主格、属格、部分格、内格/出格、上格/向格/从格；把「问什么」与词尾对上比背名字有用——missé→-ssa、mistä→-sta、mihin→-hVn、millä→-lla、kenen→-n。属格构成三种情况：元音结尾直接加 n（kissan），辅音结尾先加 i（Jasminin, Oscarin），含 K/P/T 要弱化（kukka→kukan、kenkä→kengän、paita→paidan）。公式是「属格 = 弱级 + n」，因为 -n 把词干音节关成闭音节，与第五讲第一类动词 minä 形式弱化同源。代词属格不规则：minun, sinun, hänen, meidän, teidän, heidän，口语 mun/sun/sen 只进听力不进作文。属格复数三类 -en/-jen（kirjojen）、-den（perunoiden）、-ten（lasten, vihannesten）。属格不止「谁的」：还是后置词的宾语（kahvin vieressä）和动作名词的对象（elokuvan katsominen），这解释了第六讲的结构。

例 1　写出 kissa、kuppi、paita、kenkä、ilta 的属格，并标明交替。

解：kissa → kissan（无交替）；kuppi → kupin（pp → p）；paita → paidan（t → d）；kenkä → kengän（nk → ng）；ilta → illan（lt → ll）。

思路：先看有无 k/p/t，有就取弱级词干，再加 -n。无交替时直接加 -n。

例 2　把「蒂莫的公文包是新的，安娜的书很重」译成芬兰语。

解：Timon salkku on uusi. / Annan kirja on painava.

要点：Timo → Timon（元音结尾直接加 n）；Anna → Annan。属格修饰语在前，中心词 salkku、kirja 用主格作主语。

例 3　把「学生们对书的价格有意见」改写成一句芬兰语，需用属格复数。

解：Opiskelijoilla on mielipide kirjojen hinnoista.

拆解：opiskelijoilla（学生，-lla 表「有」的主语）＋ on ＋ mielipide（意见）＋ kirjojen（书的，属格复数）＋ hinnoista（关于价格，出格）。整句结构是 X:llä on mielipide Y:stä。

例 4　改错：Minun ystävä on kotoisin Saksasta. 在正式书面语中应如何写？口语中呢？

解：正式：Minun ystäväni on kotoisin Saksasta. 或省略代词 Ystäväni on kotoisin Saksasta. 口语：Mun ystävä on kotoisin Saksasta.

说明：原句在口语里可以接受，但正式文本应加 -ni。这是「同一句话两套语体」的典型例子，考试按文体要求选择。

  1. 写出下列词的属格：kukka、hattu、tauko、kipu、kampa、räntä、kerta、Jasmin、Oscar、Martin。
  2. 写出六个人称代词的属格，并各造一句 … on uusi / painava / kylmä 的判断句。
  3. 把下列短语译成芬兰语：安娜的丈夫、我们的老师、芬兰语课、咖啡旁边、学生的意见（属格复数）。
  4. 给 kirja、koira、opiskelija、nainen、peruna 造属格复数。
  5. 改错：kukkan on kaunis / Oscarn kirja / minun kirja（正式语体）
答案与思路

1. kukan（kk→k）、hatun（tt→t）、tauon（k→∅）、kivun（p→v）、kamman（mp→mm）、rännän（nt→nn）、kerran（rt→rr）、Jasminin（加 i）、Oscarin（加 i）、Martinin（加 i）。

2. minun / sinun / hänen / meidän / teidän / heidän。例句：Minun puhelin on uusi. / Sinun laukku on painava. / Meidän luokka on kylmä.

3. Annan mies / meidän opettaja / suomen tunti / kahvin vieressä / opiskelijoiden mielipide。

4. kirjojen、koirien、opiskelijoiden、naisten（-nen → -sten）、perunoiden。

5. kukka on kaunis → kukan 需弱化：kukan on kaunis 仍不完整，正确句如 Kukan väri on kaunis；Oscarn → Oscarin；minun kirja → minun kirjani。

必考属格单数的三种情况（元音、辅音 + i、辅音交替）、六个人称代词属格、属格复数的三种词尾、Kenen? 问答。
易错 1属格忘弱化：kukkan、kuppin。
易错 2辅音结尾名字不加 -i-：Oscarn、Jasminn。
易错 3口语与书面语混用：作文里出现 mun、sen。
进阶能用「闭音节 → 弱级」解释属格为何弱化，并把它与第一类动词 minä 形式的弱化联系起来。

属格操作清单

写属格单数四步

  1. 看词尾：元音结尾直接加 -n；辅音结尾先加 -i- 再加 -n
  2. 看词内是否有 k/p/t，有则取弱级词干
  3. 看是否 -nen 结尾：→ -sen（nainen → naisen）
  4. 落笔后回读一遍，确认没有多写辅音

写属格复数三步

  1. -nen 结尾 → -sten（naisten、vihannesten）
  2. i 结尾 → -jen（kirjojen、koirien）
  3. 其余 → -den 或 -jen（perunoiden、opiskelijoiden）
